# Prespecified replication with out-of-fold expert predictions on Wisconsin Diagnostic Breast Cancer

## Question and boundary

Does a single additional nonlinear input to OKAPI's locally fitted signed affine head improve held-out binary Brier compared with the public flat logistic stacker and a head with the same extra coefficient and tree topology? Wisconsin has been examined in an earlier research round. This is a replication on a fresh partition; that history means it is not an entirely unseen dataset. Keep the native scikit-learn labels, where class 1 denotes the benign category. Clinical interpretation and patient deployment are outside this measurement.

## Fixed pipeline

Reserve a single stratified 40% outer test set with seed 87299. Nothing on the new test partition chooses a hyperparameter, fusion transform, expert pair or report contrast. Use the other 60% for five-fold shuffled stratified OOF predictions, seed 87300 for the primary bank, 87301 and 87302 as development-fold sensitivity checks. Within each fold, fit six algorithms only on its training rows: standardized L2 LR (C=1), standardized five-neighbor distance-weighted KNN, Gaussian naive Bayes, random forest (100 trees, min_samples_leaf=2), histogram gradient boosting (60 steps, max_leaf_nodes=7, l2_regularization=1, early_stopping=False) and Gaussian LDA with default solver. Forest and boosting seeds are bank seed + fold index. Refit each base on all development rows to predict the outer test (fixed random seed 87310). Preserve zero probabilities in the two supplied channels. The public stackers and native transform implement their own standard clipping.

Fit simple averaging, public ranked-prefix Top-N with binary Brier, public probability- and logit-feature C=1 regularized stacking. Use the same OOF rows and labels throughout. Each flat stack transfers into OKAPI's published binary affine tree; compare probabilities with the sklearn reference. For each transform pick the pair with largest mean absolute difference in positive probabilities on development OOF rows (first lexicographic pair on ties), then add max(A,B) as exactly one native subtree. No group labels, source-label correlations, oracle graphs or number of latent groups are provided. The dimension-matched control adds max(A,A) for the lower-index member of the same pair, with identical native topology, number of slots, supervised fits and solver settings. The repeated input changes the effective L2 penalty; this is part of what the control tests. Flat versus augmented heads differ by one provider feature pair. Fit each augmented recipe once on OOF rows using precisely the public stack's standardized two-channel objective, then transfer to the native tree. Measure maximum absolute reference discrepancy, aiming for at most 1e-9. Also score stock bounded OKAPI GP (seed 61, one restart, ten seeded trees, 16 generations, 11-node cap, Brier fitness). Report this separately budgeted search and count optimizer iterations, supervised fits, tree sizes and elapsed time.

## Evidence and interpretation

Primary bank 87300, logit transform. Predeclared success needs lower paired bounds above zero for both (flat risk − augmented risk) and (duplicate control risk − augmented risk) on the same held-out rows. Use 20,000 shared row-bootstrap resamples, seed 87320, one-sided percentile bounds at 0.025 per comparison. Report binary positive-class Brier, fit and outer-test, plus accuracy as secondary. Report both public stackers and both transforms, all fits, and the latter two OOF banks as sensitivity checks on the same test people; those banks are not independent test replications. Report negative results and the size of the compatible effects. A failed improvement does not establish equivalence. There are no group IDs or independent sites available; the estimand is a stratified random split of the bundled population. No distribution-shift or clinical generalization claim.
