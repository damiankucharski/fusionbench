# Does training-environment variation reveal a shortcut without discarding a real specialist?

This manual series has ten synthetic rounds. All ten compare regularized native-pattern OKAPI (GP seed 0, split seed 0, eight GP validation finalists), arithmetic mean, Brier-ranked best-prefix Top-N and probability logistic stacking (C=1). Compare all 30 standard-v6 scenarios each round. No test labels, target frequencies, simulator roles, scenario identifier or test-time environment enter fitting or selection on a new bank. Every procedure fits its fusion on all source rows available to the native reference, subject to that procedure's usual internal split. The primary metric is full-class Brier, lower is better. Record macro-F1 and deployed provider counts.

## Source designs and controls

Four build-in-study designs cross variation in genuine expertise with variation in shortcut activity. Each source has two equally sized, observed environments. In homogeneous both environments have region prevalence .5 and shortcut activity .5. In varied, region prevalence remains .5 but shortcut activity is 0 and 1. In case_mix, prevalence is .15 and .85 but activity remains .5. Mixed varies both (.15,.85 and 0,1). Thus all four designs have the same marginal source prevalence and average shortcut activity, but their joint distributions may differ. Each includes a stable generalist, a region specialist, an observed cue revealing the region, and a model using a possibly unreliable shortcut. An active shortcut is 90% correct; an inactive one has 50% accuracy. Focal provider order is anonymous and separately permuted for every seed. Standardize all four forecast magnitudes to .8/.2 by vote sign, except in the named amplitude sensitivity control. Source context is the observed region cue, such as a recorded task or acquisition setting, supplied separately for adjustment. The audit alone uses true role indices to count correct or erroneous exclusions. No search over masks on test outcomes.

The focal tests share 16 report patterns and use their analytic joint input-label probabilities. Targets s0, s50, s100 have prevalence .5 and 0%, 50%, 100% active shortcut. R3/4/9/10 also use specialist80 (prevalence .8 and activity .5). R10 also uses s25 and s75. One fit is reused across all worlds. Within a source design the downside of full reliance on the trained system is its worse Brier of s0 and s100, computed separately for each fitted model on each seed before averaging. Report individual endpoint costs, even when worst-case loss improves.

The standard panel supplies a regression stress test. Simulated scenarios need not supply acquisition environment labels. Explicitly create a **proxy** partition for screening only: split source rows into lower (<= median) and higher provider disagreement, measured as mean squared class distance from the provider average. Split the confidence of that average (max class probability) at its median to define an observable adjustment stratum. In the three known scene-clustered standard presets use a single deterministic random representative per training scene for diagnostics, then give every candidate the entire original source bank for fusion. Native with no usable environment IDs is the fallback. An inferential claim about actual site labels requires additional data.

## Decision rules

Measure a provider's Brier within each source environment. The raw rule compares the difference between environment means. The adjusted rule standardizes each mean over common pooled empirical context proportions, abstaining if any required cell has fewer than eight examples. For an environment mean use the sum of squared stratum weights times the sample variance divided by stratum size for its variance estimate. Score a provider by the largest pairwise absolute difference minus z times its joint standard error. If there is a unique largest provider score strictly above threshold, omit that provider before running the native procedure; otherwise fit ordinary native. No more than one provider may be removed. Raw and adjusted use z=1.96 and threshold .10. Strict uses adjustment, z=2.58 and threshold .15. These are screening heuristics after comparing providers and environment pairs. The sham permutes the real source environment IDs with a separate reproducible draw while preserving source predictions, labels, context, and counts, then uses the adjusted rule. Standard, sham and native test the cost of unstable or uninformative environment labels.

| Round | Question |
|---:|---|
| 1 | At the same number of source labels and the same average training exposure, does varying shortcut activity reveal its identity and improve worst-endpoint risk relative to homogeneous exposure? |
| 2 | With the source sample held exactly fixed, do correct environment IDs contribute beyond pooling the training data or randomly permuting the IDs? Include the sham in this and all later rounds. |
| 3 | When only regional prevalence varies, does raw filtering remove the genuinely useful specialist? Test separately where the region is frequent. |
| 4 | When both mechanisms vary together, can adjusting for case mix separate shortcut drift from a change in the number of specialist cases? |
| 5 | At fixed total of 512 examples, compare two mixed environments to four (`four_env`, two copies per regime). Does splitting up the evidence alter decisions? |
| 6 | How much environmental contrast is needed? In `narrow` change the two source activities to .25 and .75 with the same average. |
| 7 | Does the diagnosis survive with only 128 source examples, still balanced across environments (`small128`)? The full panel remains 512. |
| 8 | Separate reporting scale from context quality. `original_scale` retains the original role-specific confidence levels. `noisy_context` flips the observed side-channel context for 25% of source examples in expectation, keeping all model predictions and labels fixed. |
| 9 | Pick one of adjusted, strict and raw by the lowest mean of per-seed worst (s0,s100) Brier on mixed. Use that action order for an exact tie. Commit the selection and input hash before confirmation. |
| 10 | Confirm on independent source and test draws. Require upper paired 95% endpoint below zero for chosen minus native on mixed worst-endpoint risk. Separately require upper endpoints <=+.005 for standard macro Brier, case_mix/specialist80 and mixed/s100 to claim broader protection. Also assess the held-out reversed association of source prevalence (.85,.15) to activity (0,1), the narrower source span, small128, and two unselected target mixtures. |

All rounds use disjoint data seeds. For round r use base=840000+1000r; standard offset 400, focus offset 100. Standard uses 2/4/8 draws per family in R1–8/R9/R10, with 512 source and 512 test examples. Focus uses 8/12/24 draws per design in those blocks. Each standard family gets equal weight. Resample independent seeds within fixed families for the standard panel and matched source seeds on the focal designs (10,000 paired bootstrap draws, seed 83000+r). No unregistered rounding or tie margin is used when selecting the final policy. Real data and further rounds are outside this series.
