# Does differentiable majority likelihood recover the unknown axes?

Round starts 2026-11-20 23:49:24 UTC. All runs use raw isotropic nine-dimensional Gaussian inputs, a new random orthonormal set of three latent axes, labels equal to majority of signs, and no expert weights, probabilities, local labels, view membership or second teacher network. Freeze seeds 900–911 and nested sample sizes 512 and 2048. Use 4096 paired independent query vectors per seed. One test intervention multiplies one randomly chosen latent coordinate per query row by four and both others by one half, holding nuisance coordinates and the true label fixed. Directions are available only for ground truth, scoring and constructing this test intervention.

Each main network contains the same three dense affine leaves. Train one with the hard median of logits, the other with the exact differentiable log-odds that three independent Bernoulli events have a majority. Both know the rule. Compare identical initial parameters and 600 minibatches of 64 with Adam .015 at both label budgets. Evaluate every learned leaf set with both output rules, including median decoding after smooth training. Add smooth training from exactly duplicated leaf parameters as a symmetry control, standard one-hidden-layer ReLU network (3 hidden units), and a raw linear model. Nothing is selected on query rows. The primary comparison at 512 labels is smooth-trained versus median-trained under the same median decoder on (a) shifted Brier and (b) mean signed cosine of learned true axes after an optimal permutation. Report IID Brier, accuracy, 95% paired t intervals over seeds and all baselines. The smooth independent-event likelihood is a training model for uncertain latent signs and need not numerically equal a median decoder.
