# A single cross-fitted OKAPI hybrid versus both logistic stackers

Freeze before running any fresh banks. Primary outcome is full-class Brier on independent IID examples, averaged equally across all 19 default FusionBench scenarios. The candidate uses regularized logistic regression on provider logits, the same regression on raw probabilities, and one native OKAPI tree. Its weights are learned independently on each training bank. For attribution we also compute the corresponding two-component linear-model blend using identical out-of-fold predictions, plus the standalone GP. All seven comparisons (hybrid, two individual logistic stackers, LR-only blend, GP, arithmetic mean and ranked-prefix Top-N) use the same 640 labeled training rows and provider columns. Report actual execution time; this is label-matched, not compute-matched.

Use FusionBench 9af5f79, OKAPI 3eae0e5. Each of 12 independent replicate indices (0 through 11) supplies a separately seeded bank to every scenario. In registry order use data seed 1320000 + 1000 × scenario index + replicate. Training, fresh IID and the nine previously defined shifts use streams 0, 1 and 2, respectively; 640 training and 4096 test rows per split. No scenario-specific choice of component, palette, hyperparameter or weight. Search and fold seeds use a common deterministic rule from each data seed. Fixed default scenario parameters; this evaluates the known registry on fresh samples.

Use three shuffled stratified outer folds with seed equal to the data seed. For each training partition fit both public FusionBench logistic stackers independently (C=1, native scaler). Fit a native tree using the existing mixed_branch initializer, the six-family palette, and 600 real objective calls. Split each training partition by an independent deterministic permutation, first floor(0.8 n) rows for evolution and the remainder for archive selection by Brier (fit loss breaks ties). Never use outer held-out rows to search or select their predictor. Use the same procedure for the final component fits on all 640 rows. Fit the convex combination minimizing full-class Brier on the stitched outer held-out predictions: one nonnegative weight per component shared across all classes, weights summing to one. Use the vertices, every segment optimum, and the unconstrained optimum inside the triangle; ties prefer earlier candidates. Fit the LR-only blend by the same procedure on the first two components only. Refit each component once on the complete training bank, carry the out-of-fold weights forward, and freeze everything before evaluating either test. Entirely new GP trajectories in this round. No oracle use or selection of weights using test data.

For each replicate compute each paired difference averaged over the 19 families. Report a two-sided 95% t interval on the twelve replicate averages (uncertainty for new data/search seeds on these fixed families). Declare a win over logistic stacking only if the upper limits of hybrid-minus-logit and hybrid-minus-probability LR are both below zero, and claim incremental value for the tree only if hybrid also beats the cross-fitted LR-only blend by that criterion. Report absolute losses, family-level win/loss counts, per-family differences, leave-one-family-out mean contrasts, full class probabilities for multiclass tasks and the nine distribution shifts as secondary outcomes.
