# Does the fitted operator explain the gain after admission?

Prospective joint design. On earlier FAR-switch banks, giving a fitted gate to the breeding population beat storing the same gate only in the archive. Admission also replaced and reordered parents and could change the random trajectory. This experiment holds the admission event and slot fixed while varying which information the proposed operator carries. The OKAPI Lab supplies controlled native variants and lineage markers. FusionBench owns the matched-state forks and independent evaluation. [Earlier admission result](native-graft/README.md) · [Prior audit of existing threshold parameters](native-refinement/README.md)

**Freeze.** Use 16 fresh data seeds 4100–4115 and GP seeds 311 and 313. Generate separate fits for three conditional label laws on the same six anonymous dyadic provider scores, hidden ordered signal pair and paired uniform draws. FAR selects the signal value farther from 27/64; CLOSE selects the one nearer 37/64. At distance ties the first signal wins. The logistic rule is sigmoid(0.2 + 0.7 logit(A) + 0.7 logit(B)). Each regime has 512 fit, 256 independent validation and 8192 independent test rows. Evaluate every fitted procedure on all three test laws, with identical held-out features. Record observed positive-channel Brier and mean squared error to the known conditional probability (excess Brier). All learning and proposed edits receive only fit labels and anonymous predictions. Save fit and independent validation archive champions separately. Include all-provider mean, once-ranked Top-N scored on every prefix, regularized logistic stacking and the exhaustive empirical single-gate reference on the same fit data in every regime. The additional CLOSE task is an intentionally constructed transport control. Its generating cutoff has no special status in search.

**One proposal, common costs.** Pause the ordinary six-operator NumPy OKAPI process at the first complete generation whose native fitness-call count C is at least 1200. Use six singleton initial trees, multiplier and tournament two and native rounding. At one randomly selected terminal of the best-seen fit tree, try all five other suppliers and both ordered CLOSE/FAR directions. Fit each threshold on the true downstream Brier through the native wrapper and event solver. Use the first uint32 word from SeedSequence([data_seed,gp_seed,937]) for the graft site's local RNG. Keep the first strict fit improvement in the declared order. The full proposal has F=41 native forwards and T tested scalar threshold candidates. Fit labels determine the selected operand and direction. The true roles and laws remain hidden.

For an improved proposal prepare four new native programs. In one factor keep the selected new operand or replace only that new operand by a second copy of the terminal's original provider. In the other keep the fitted threshold or reset it to 0.5. All four retain the same site, node count, ordered operator type and all previous parameters. CLOSE(A,A) and FAR(A,A) return A on every real row for either threshold; their offsprings' later mutations can expose the inherited cutoff. Count one extra native fit forward for each of the three alternate versions to verify their actual fit losses. For the fully fitted version reuse its already charged score. If the proposal made no strict improvement, return the original unchanged for all four and charge no variant-generation forwards. Create the same unmarked candidate archive for all six experimental forks, in order pair/fitted, pair/0.5, duplicate/fitted, duplicate/0.5 after the observed archive at C. Ties retain the earlier program. Each immediate prediction and the following search therefore have the same external candidates available for final selection.

**Match admission before varying the parent.** Run the ordinary native survivor decision for the fully fitted proposal, starting from the same six parents and RNG. Record their original indices, output order, the offered parent's slot, the displaced parent, and pre/postselection RNG digests. Separately evaluate the decision for every variant as if offered alone from the same untouched state. These shadow decisions diagnose admission bias. If the fully fitted proposal is unchanged, a duplicate, or rejected, all experimental arms retain the original six parents, order and RNG. Analyze every such pair in the primary comparison.

For an actual admission, fork six states. The first four place the corresponding variant in the one designated slot with its *own* correctly rounded training fitness; the other five parents, their fitness rows, order and postselection RNG are identical. The reorder-only control places the original displaced parent in the designated slot with its old fitness, keeping all six old parents and the matched postselection RNG. Archive-only keeps the original parents, order and unmodified RNG. The forced placebo interventions answer a mechanistic question; the algorithm would sometimes reject those variants if offered in isolation. Allow genuine duplicate structures in forced slots, recording their counts; ordinary deduplication resumes at the next native generation. Carry out exactly 300 more native objective calls from each fork. Also continue untouched ordinary GP to C+300, C+F+variant-forwards+300 and C+F+variant-forwards+T+300. Track real forwards, candidate thresholds, wall time and the archive/population state separately.

**Endpoints.** Primary: under the FAR law, fit-selected excess Brier after 300 ordinary calls, fitted-pair/fitted-cutoff minus duplicate-anchor/fitted-cutoff, with all 32 bank/restart pairs included. This contrast changes only the new operand ID at intervention; it holds structural complexity, fitted number, event, slot, other parents and RNG fixed. Training fitness is derived from the resulting real predictions, so the contrast includes its downstream effect on selection. Compare the same frozen contrast on CLOSE and the logistic law. Secondary controls hold the pair fixed and change the threshold, or hold initial predictions fixed in the duplicate cells and change only the stored cutoff. Decompose the fitted-minus-archive mean difference along the explicit fitted → duplicate/fitted → reorder-only → archive-only sequence; it is one prespecified sequence of policy contrasts. Report natural admissions, conditional outcomes on admitted pairs, and originally gate-free trees as diagnostics. Estimate two-sided t intervals from 16 independent bank-level mean differences, averaging restarts within each bank. Reserve causal claims about this synthetic, slot-matched intervention.

**Lineage and validation.** Create the common archive before attaching a prediction-inert lineage marker only to the new gated parent placed in an admitted fork. Track its propagation on each subsequent native objective call, including repeated evaluations and copies of already-seen structural keys. For the winning program distinguish a marked first archived occurrence from any subsequent marked copy of the same program and check retention of the original fitted cutoff/direction. Audit that marking leaves predictions, structural keys and search trajectories unchanged in replay. Under non-admission compare all six actual path digests and both archived winners. Independently check equal initial predictions and fit for both duplicate variants, full-cost controls, all baseline metrics, and ordinary/forced native continuation. Publish null outcomes and failures of transfer.
