# Exact search and generalization audit

Four binary provider events give 16 possible input rows. Each provider reports positive probability 0.125 or 0.875. Decisions use score strictly above 0.5. An unrestricted-size tree composed exclusively of MIN and MAX realizes exactly one of 166 nonconstant monotone Boolean functions. Conversely, every such function has an OKAPI representation as the maximum of its minimal conjunctions, each a minimum of provider values. Reusing providers or reordering operators cannot expand this function set. We will enumerate it independently of the stochastic search and log every distinct 16-cell decision vector reached by the optimizer.

## Design fixed before measurement

- Primary task is (A AND B) OR (C AND D) with independent 18% label flips. A mismatched control uses A XOR B with the same flips. An additive control uses conditional positive probability sigmoid(1.5 × (number of positive providers − 1.8)).
- Fit and validation use independent balanced provider events. The shifted test changes only input prevalences to (0.8, 0.15, 0.75, 0.20). Conditional label probabilities stay fixed. Compute exact population zero-one risk by weighting all 16 cells. Also report realizations on independent IID and shifted test samples of 4096 examples each.
- Fit sizes 32 and 128 use nested rows. Validation size 128. Cross independent data seeds 3000–3007 with GP seeds 31 and 47. Log search after 1, 4, 16 and 48 generations. These are fixed runs, with population 4, multiplier 2, tournament size 2, complexity on the Pareto front and default mutation settings. Each search begins with the four provider trees. A single seed outside this panel may be used for integration testing.
- Run the actual OKAPI engine both with MIN/MAX only and with the six default operators. Archive empirical-accuracy champions among evaluated candidates, breaking tied earliest discoveries deterministically. Record objective calls, distinct decisions, wall time and complexity of retained population winners. Compare the retained fit winner and a candidate chosen by validation loss from the visited decision functions. Validation-selected and fit-only results use different amounts of labeled information.
- For the exhaustive MIN/MAX empirical optimum, ties favor fewer DNF literals and then lexicographic order. Report the number of tied optima and range of their population risks. Primary optimization endpoint is the MIN/MAX archive champion's excess count of empirical errors relative to that exact optimum and its probability of hitting zero across seeds. Generalization endpoints include exact IID and shifted excess risk relative to the population-best family member, and the gap between exact population risk and realized fit error. Include the population Bayes risk and its difference from the family oracle to measure misspecification.
- The default broader GP is compared to the exact empirical lower bound over *all* binary classifiers on 16 cells (the minority-label count per cell). Its difference from the restricted MIN/MAX optimum is only a signed comparison. The unrestricted lower bound can be unattainable with the default primitives.
- Arithmetic averaging and the repository's regularized logistic stacker use the same provider scores. Logistic stacking fits exactly the same labeled rows used for GP fitness. Use uniform sampling of unique monotone functions as a search reference at the same number of distinct phenotypes visited by restricted GP. Fitness on the entire cube uses training label counts as sufficient statistics; unobserved cells have zero weight. Test and validation labels never influence GP fitness.
- Summaries average stochastic restarts within each data seed before comparing methods. Interpret conclusions at this finite noise level, input dimension and population size. This protocol evaluates optimizer behavior and estimator behavior in a deliberately tractable problem.
