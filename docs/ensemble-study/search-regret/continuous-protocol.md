# Exact empirical Brier oracle for unrestricted MIN/MAX trees

Test the following construction on continuous binary-provider scores. A monotone lattice rule corresponds to an upward-closed collection of active subsets of providers, with the empty set rejected and the full set accepted. For each labelled row, sort its distinct scores and telescope the loss differences along its chain of thresholded subsets. Adding all rows produces one unary weight per subset. A minimum-weight closure over the Boolean lattice should yield a globally optimal empirical tree. Use integer capacities representing the supplied float64 scores exactly and verify an attaining rule against the optimum. This certificate concerns unweighted positive-channel Brier loss, unrestricted tree size, and the MIN/MAX operator family.

Validate independently against enumeration of all 166 trees on at least 30 small continuous problems, including duplicated scores, repeated rows, constant inputs and conflicting labels. Compare at eight continuous providers using existing FusionBench TwoPathways(rep=2), with fresh data seeds 3400–3407. Use 128 nested fit rows (also evaluate 32), 128 validation and independent IID/shifted test samples of 8192 per domain; reduce detector accuracy from .90 to .78 for shift. Search with the actual native MIN/MAX optimizer from singleton providers, population eight, tournament two, multiplier two, three GP seeds 131–133, tracking archive fit/validation winners at 300 objective calls. Compare exact empirical winner, GP fit and validation winners, average and logistic stacking. Record unrounded fit Brier regret relative to the certificate, held-out IID/shift Brier losses, oracle wall time, and size of the certified minimal-conjunction form. The primary endpoint is archive fit regret at 128 labels. Exact population risk is unavailable on this continuous distribution; sampled test losses estimate it. Measure dispersion across independent data draws rather than treating restarts as independent datasets.
