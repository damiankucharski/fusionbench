# Does pruning functionally equivalent MIN/MAX trees improve GP?

Prospective follow-up registered 2026-11-21. In the preceding paired audit, all naturally observed printable-key collisions in the MIN/MAX panel involved equal functions. The distinction between a structure and a function also permits an exact intervention. Use the Boolean signature of each lattice expression on every binary assignment as its functional key. For eight providers this is a 256-bit integer. MIN/MAX commute with every threshold, so equality of these keys means equality on the entire continuous input cube. A different structure can nevertheless have different descendants under crossover and mutation. Either time spent on equivalent programs or access to their descendants could dominate.

Run native OKAPI at 86f21cd with only the joined-population first-occurrence key switched. Compare the default ordered structural identity with exact full-cube functional identity. In each condition leave the actual singleton initializer, eight-member population, tournament two, multiplier two, zero survivor-fitness reuse, NumPy, MIN/MAX repertoire and optimizer rounding unchanged. Never use labels to compute a signature. No migration. Neither the genotype archive nor the validation rule restricts the search. Include the same cheap frozen baselines in both comparisons: all-provider average, individual fit-Brier ranking followed by mean of the best fit-Brier prefix among all eight, and regularized logistic stacking.

Freeze twelve new TwoPathways data draws 3600 through 3611, each with four GP seeds 211, 223, 227 and 229. Reuse the published continuous scenario and split scheme with 128 fit labels, 128 validation labels, 8192 IID and 8192 shifted examples (0.90 to 0.78 detector accuracy). The primary endpoint is the paired difference (functional minus structural) in best-seen fit Brier regret at 300 objective evaluations. Secondary checkpoints are 1200 objective evaluations and the completion of generation 20. The fixed-generation comparison helps distinguish additional generations per evaluation budget from differences in what programs get proposed. Count each actual objective evaluation including repeated parents. Choose archive champions by fit Brier, and separately by validation Brier, breaking validation ties by fit loss and remaining ties by first encounter. Freeze selections for both test domains.

Measure the empirical global MIN/MAX optimum by integer min-cut, exact hit counts, Brier and node counts. Log the number of distinct structures and functions evaluated, mean and maximum number of essential providers per distinct function, joined candidates and the number of structural first occurrences representing an already present function. Record observed key runtime, search wall time and per-seed transitions in the winner. Treat the 12 data draws as independent and aggregate restarts before estimating a paired two-sided t interval. Report effects even when zero or adverse. The inference scope here is this single, monotone synthetic setup; full truth signatures have exponential cost in provider count and apply only in the specified MIN/MAX grammar.

Verify the bitset implementation against native predictions on the Boolean cube. Check that applying each mask to a population retains first occurrence of its assigned keys and that every unique function in the joined batch has a representative under either policy. Keep synthetic test labels, pure-corner probes and exact fitted solution out of optimizer fitness.
