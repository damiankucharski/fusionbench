# Controlled initial-population intervention

The arity-matched reference identified a gap in the functions GP visits. The following test changes only the four initial trees of the actual MIN/MAX engine. The fitter, four-individual population, variation operators and training loss stay fixed. No candidate receives target truth tables, population risks or validation labels during search.

Use fresh data seeds 3200–3211 and GP seeds 91 and 97 on TwoPathways, parity and additive labels at fit sizes 32/128. Use the existing independent 128-label validation set, IID/shift populations, 4096-row test samples and generator. Compare the stock singletons; one uniformly drawn finite-family function of each essential arity; four uniform finite-family functions without replacement; and four balanced binary min/max compositions each using all four providers exactly once with random ordering and random operators. The finite-family draws compile to DNF trees, giving the optimizer a different initial architecture; balanced four-input trees have seven nodes and require no prior enumeration. The balanced grouping happens to include the TwoPathways topology. Additive and parity controls test transfer and possible harm. Function priors and initial tree sizes differ, so this intervention identifies a change of initialization policy.

Measure archive outcomes after exactly 4, 80 and 300 fitness evaluations. The first checkpoint measures the starters alone. Search may finish its enclosing generation; only the specified prefixes enter analysis. Compare uniform proposals without replacement at the same upper-bound budget, stopping after the 166th distinct function. Report measured evaluation time and number of distinct functions since equal candidate counts do not guarantee equal compute. Primary endpoint is paired train regret of one-per-arity versus stock at 300 calls on 128-label TwoPathways. Also report exact IID and shifted population risks, the two control tasks, archive validation selection with 128 extra labels, mean initial node count and empirical-hit frequency. Average the two restarts inside each dataset before contrasts. A lower train regret with unchanged or worse IID risk would separate improved optimization from improved generalization.
