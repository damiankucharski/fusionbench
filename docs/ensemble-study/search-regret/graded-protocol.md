# Confirmation with graded probabilities and a proper scoring rule

The earlier hit-rate experiment thresholded four binary provider values and used classification accuracy. This round tests whether the optimization and overfitting diagnoses survive a change of target, input resolution, loss and starter draws. Use four providers, each taking one of (0.10, 0.35, 0.65, 0.90). All 256 input cells have known probabilities. Log Brier loss per binary positive channel.

The same 166 canonical nonconstant MIN/MAX programs exhaust the tree family by absorption and distributivity on this ordered set. Distinct programs differ on some low/high corner. The exact population Brier risk is irreducible Bernoulli variance plus the squared distance between the rule and the conditional label probability, averaged with the population cell weights. Compute each program's exact fit and exact population Brier risks.

- Matched case: conditional positive probability is max(min(A,B), min(C,D)); permute the four provider roles separately for each data seed. Misspecified controls: conditional probability is the arithmetic mean, or sigmoid(−0.2 + the weighted sum of logits with weights .45, .65, .35 and .55). The latter also uses the random role permutation.
- IID provider categories have uniform mass. Shifted categories have probabilities (.05,.10,.25,.60) for A and C, reversed for B and D in observed coordinates. Keep the conditional law fixed. Sample independent validation and two 4096-row test splits. Also report exact population risks.
- Fresh data seeds 3300–3305 and eight independent starting/search seeds 101–108. Nested fit sizes 32 and 128; 128-label separate validation. Use identical rows for every fitted method. Measure stock MIN/MAX and the same engine initialized with one compact randomly assembled read-once program per arity 1–4. The latter draws distinct provider indices without replacement and random binary MIN or MAX at each merge, with random adjacent pair selection until one tree remains. This sampler requires no prior list of lattice programs. Keep population, objective and variation identical and compare the first 4, 80 and 300 fitness calls. Compare the training winner, the validation winner, all-166 exact empirical selection, arithmetic averaging and regularized logistic stacking.
- Primary paired endpoint: change in empirical Brier regret relative to the exact restricted optimum at 300 calls and 128 labels for the matched task. Report changes in exact population Brier risk on both distributions, the exact family approximation floor for the two controls, and comparisons against baselines. Aggregate restarts within data seed. The six independent training draws limit precision. Interpret timing separately from equal objective-call budgets.
