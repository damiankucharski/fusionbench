# Does a frozen winner use the gate it inherited?

The slot-matched study traces individual gate occurrences through actual OKAPI operations. A gate may reach the winning program yet have no effect, or may change its predictions in the wrong direction. This follow-up tests the frozen winner directly on new evaluation examples. It measures a change to a given trained program; the sibling study tests a change to training. [Prospective slot-matched design](matched-graft-protocol.md)

## Frozen programs and examples

Use all fit-selected final programs from the full, fitted-pair/fitted-cutoff arm of the preceding panel. Include all sixteen original data banks and each of their two GP starts, independently for FAR, CLOSE and logistic training (96 fit-selected programs). Also report the separately validation-selected archives. Preserve every program even if no gate was admitted or retained. Decode the exact ordered program, parameters, and paths recorded on its actual first archived occurrence. The same anonymous provider roles, fit data and validation data remain frozen. For each bank draw 32,768 **new** six-column feature rows and uniforms from NumPy SeedSequence([data_seed, 9701]), unseen by all previous procedures. Score the frozen programs under all three conditional laws on these shared new rows. This changes the mechanism but holds every feature and uniform fixed. Regenerate only the three conventional comparison models from their original 512 fit rows (identical deterministic recipes already declared); apply them without changes to the fresh test rows. These are the all-provider mean, one individual-Brier ranking with each of six prefix means scored and its best length frozen, and regularized logistic stacking.

## Interventions on the program

Score the intact native GP program and the following edits, in private copies. Jointly bypass all gate occurrences carrying the proposal's lineage marker on the actual first archived winning copy. Skipping one operation passes the parent's previous value forward to the next operator, and drops only this operation's operand subtrees. Alternatively reset the numeric cutoff to 0.5 at every same marked occurrence, keeping its direction, all operands and downstream operations. Both edits preserve the intact program when the marker is absent. Validate the native implementations against an independently evaluated ordered representation, including nested operations and distinct current operands. Count affected rows, origin occurrences, source program sizes and the post-bypass sizes. An edit that changes no output still belongs in the comparison.

As a sensitivity test for fit-selected champions, separately use the path set observed on the first actually marked later copy of the very same structural key, when such a copy was seen. Never impute a mark from mere genotype identity. On validation-selected champions only the first archived occurrence was fully traced. No marker gets assigned to old archive entries. Report results on the full ensemble of frozen starts and, descriptively, on the subset with an observed marked first archived program. Record the number of banks contributing to the subset.

## Falsifiable endpoint

The primary outcome is mean **bypassed minus intact excess Brier** on independent FAR rows for FAR-trained, fit-selected winners. Compute one difference per start and average the two starts within each of 16 independent data banks before reporting the paired mean and two-sided 95% t interval. Unmarked first-archived winners contribute exactly zero. An interval crossing zero leaves unresolved the claim that the entire program population benefits from these inherited steps at inference. A lower bound above zero supports that claim for the frozen training policy and generator. Secondary outcomes are the cutoff-reset contrast, observed Brier, affected-row fraction, stationary CLOSE and logistic controls, mechanism shifts, separately validation-selected champions, and first-observed marked structural copies. Report conditional excess error against the known q as well as realized label Brier. Also report three cheap baselines under the same law and split.

A larger bypass loss proves dependence of the trained program on the removed operations on those examples. It does not establish that no equally accurate freshly trained program exists without them, that inherited parameter values were optimal, or that removing one operation is additive with removing another. No target, baseline or hypothesis uses the new test rows for selection.
