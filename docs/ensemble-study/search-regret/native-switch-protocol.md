# Can the optimizer find a native probability switch?

Prospective joint design, 2026-11-21. FusionBench's existing GatedExperts uses a separate selector. In native OKAPI on one scalar channel a CLOSE or FAR node chooses the operand nearest to or farthest from a real threshold among the parent result and its children. The first operand wins distance ties. New thresholds are drawn uniformly and can mutate. This experiment isolates a representable native switch against a well-specified logistic control. The OKAPI Lab confirmed the paired operator repertoires at 86f21cd. The signed-affine stacking study in that repository is separate.

For each prospective data seed 3700 through 3711, hide two distinct roles A and B among six anonymous independent provider scores sampled uniformly from {1/64,…,63/64}. Fix the role permutation before drawing data and keep it the same across splits and regimes within that seed. Let qS be the farther of A,B from 27/64 with ties to A. Let qL = sigmoid(0.2+0.7 logit(A)+0.7 logit(B)). Draw each label as a Bernoulli outcome with the row's conditional probability. Fit separately on the stationary switch regime and the stationary linear regime, using the same input rows and uniforms for matched comparisons. Use 512 fit, 256 independent validation and 8192 independent test examples. On the test panel use a common feature matrix and independent uniform per row across three paired label distributions qS, (qS+qL)/2 and qL. For switch-trained methods these model steady, weakened and abolished switching. Linear-trained methods evaluated on qL provide the stationary negative control. Oracle probabilities, test labels and hidden role identities remain unavailable to every fitting and selection procedure.

Fit the arithmetic mean, ranked-prefix Top-N by fit positive-channel Brier (all six prefixes), regularized logistic stacking, best fit-gate with fixed threshold 0.5, and the exact fit-gate with free threshold. Both gate searches enumerate every ordered pair of distinct providers and CLOSE/FAR. For scores in this dyadic alphabet, all pairwise equidistance breakpoints lie on multiples of 1/128. Evaluate thresholds j/256, j=0,…,256, including every tie and an interior representative of every possible interval. This covers every distinct function realizable by a continuous threshold in [0,1] on this alphabet. Compare integer fit squared-error sums to identify all ties, selecting first by ascending parent, child, CLOSE before FAR and ascending threshold. The certificate covers only the ordered two-input, one-operator gate family. If native GP beats it on training loss, record the signed difference. The known generating q provides a separate positive and negative control.

Use actual native OKAPI with anonymous N×1 positive probabilities, NumPy, six singleton parents, multiplier and tournament two, no survivor-fitness reuse and 1200 objective calls (also record 300). Compare the default six operators MEAN, MIN, MAX, WEIGHTED_MEAN, FAR_THRESHOLD and CLOSE_THRESHOLD against those same first four. Freeze three seeds 251, 257 and 263. The operator palette intervention changes both expressibility and mutation frequencies. Record fit champion and separate validation champion over distinct visited programs at each budget. Select winners before scoring the test domains. The three cheap references and both fitted gates use identical fit rows and labels.

The primary endpoint is 1200-call fit champion conditional excess Brier on the stationary switch test, six-operator minus four-operator GP. Report observed Brier alongside conditional excess, mean squared error to q. Secondary contrasts are the empirical-fit gate versus logistic stacking by regime, the gains from a learned versus fixed threshold and changes as switching weakens. Track exact gate recovery on the full 63×63 signal-pair grid when the selected ordered pair matches up to permutation, identified roles, threshold/operator usage, sizes, archive sizes and objective cost. Report intervals from the twelve dataset-level paired means, averaging restart outcomes within each data seed. Unresolved and adverse results count as evidence. This is a deliberately constructed mechanism test on synthetic probabilities, with test domains differing only through their conditional label law.
