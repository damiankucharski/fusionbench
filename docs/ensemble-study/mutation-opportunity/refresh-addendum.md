# Independently seeded parameter-refresh sensitivity test

Added on 2026-11-21 while the preregistered panel was running. The Wine retype-minus-identity main contrast had been communicated to the researchers; none of the comparisons involving refresh or any new synthetic outcomes had been inspected by the investigators deciding this addition. The accepted four-arm protocol and its full results remain reportable. [Original protocol](protocol.md) · [Original native implementation](https://github.com/damiankucharski/OKAPI/blob/1ae37a58f6d3dd3296c1f6c716ec6d5317b0facd/experiments/point_ablation/moves.py)

In the original refresh control, the fitter copies the native random-generator state immediately after an ordinary point proposal. A refreshed threshold can consume the same uniform variate that the engine subsequently uses to decide whether another mutation occurs. This can couple a parameter's numerical value to a later discrete decision in this control. The stock, genuine retype and identity arms use no shadow parameter draw. The primary retype-minus-identity endpoint is unaffected.

Add one separate arm, refresh_independent. Keep the same eligibility, transition opportunities, original operator family, site and ordered children. Execute the ordinary proposal and derive a deterministic private substream using a domain-separated cryptographic hash of the full native post-proposal RNG state. Fresh parameters of the retained family use that stream. The extra pool neither consumes native draws nor starts from the next variates of native GP. Preserve and replay the original four arms, and run only this additional control at the same costs and both frozen stopping rules.

The paired sensitivity estimates on the 19 fresh families and Wine are independent-refresh minus original refresh, independent-refresh minus identity, and genuine retype minus independent-refresh. Use the original fit-selected and validation-selected archives, same paired banks, same two restarts and budget logic, and the original three baselines fitted and frozen on identical rows. Report the fixed-suite average with its bank-level interval, per-scenario spread, and all five paired Wine folds with their sample-weighted pooled contrast. A different result between the two refresh implementations would qualify any inference about renewing parameters. Both variants with compatible results increase confidence in the diagnosis within this panel. This is an additional control on the same evaluation data. A claim of transfer to other domains continues to require separate data.
