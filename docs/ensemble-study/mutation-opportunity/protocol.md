# Isolating the effect of replacing an existing operator

Frozen on 2026-11-21 before training the four-arm panel. The earlier deployable flag improved mean IID full-class Brier by 0.00892 across the 19 default scenarios. Adding an eligible fourth mutation also changes how often a tree receives each of the three ordinary moves. This test asks whether replacing the operator itself adds value beyond that change. The previous study did not include an opportunity-matched control. [Previous per-scenario estimates and dispersion](../full-suite-point/README.md)

## Interventions

Use the same initialized native GP and six ordinary operator families as the preceding full-suite protocol. The four arms are as follows.

| Arm | Action when the dispatcher selects the new mutation |
|---|---|
| stock | Disable the new mutation. Native variation follows its original distribution. |
| identity | Enable the new slot. Draw its native site, alternative family and new parameters. Return the original genotype with its native variation state preserved. |
| refresh | Draw the same ordinary proposal as in identity. At the selected site retain the original family and ordered operands and initialize that family's own parameters afresh. Use a copy of the local random state so extra parameter draws never advance the GP stream. A family without parameters produces the original genotype. |
| retype | Enable the published option. Return the ordinary native replacement with all child subtrees and their order preserved. |

Eligibility, construction of the native alternative, common starting RNG and incoming genotype are identical across the three enabled arms at the first eligible common event. After a genotype or fitness differs, subsequent lineages can diverge. Record costs, point opportunities, their changes in family and genotype, and duplicates discarded before scoring. A structural copy and a changed prediction can differ. This is a four-arm ablation. A common parameterization across different operator families is unavailable.

The main comparison is retype minus identity on fresh IID full-class Brier after **1200 actual training fitness evaluations**, selecting the archived tree with the lowest unrounded training Brier. A negative difference favors the ordinary retype. The prespecified estimate averages both starts, then weights the 19 fixed scenarios equally within each of six independent data replicates. Give a two-sided paired 95% t interval across these six replicate averages. This interval addresses repeated data draws for this fixed panel. The confirmatory test concerns this fixed synthetic panel and metric. Secondary estimates are retype minus refresh, refresh minus identity, identity minus stock and retype minus stock. Give per-scenario paired intervals across its six banks, including unfavorable and inconclusive cases. Repeat these analyses after **10 completed native generations** on the same trajectories. That endpoint allows evaluation counts to differ. For a fitness-clock checkpoint within a generation, logging may have already seen structural proposals from the rest of that cohort. The ordered objective, selected trees, and archive stop at the specified score. Initial native fitness calls count.

Use a secondary minimum-validation-Brier champion from each identical archive, with lower fit Brier then original archive order to break ties. Also report fit and validation scores, accuracy, macro F1, log loss, conditional excess when oracle available, node counts, training/validation evaluations, distinct genotypes, generations and duplicate rejections. No hold-out labels affect evolutionary proposals, thresholds or tie rules. Report whether the same interpretation holds at fixed calls and fixed generations.

## Regression families

Use all 19 canonical families, including the 100-provider needle, the four-class saturated case and the five-class multiclass committee. Reuse the unchanged common GP settings, binary representation, operator-local multiclass simplex normalization, and nine named shifts from the previous protocol. Use six new independently seeded banks 5100–5105, with 384 fit, 256 validation and 2048 each IID and available shift; both new GP seeds 661,673 share each bank and all treatments. The choices of panel and methods are fixed before observing new outcomes. Means across scenarios describe this finite registry. [Exact settings and nine shift parameters](../full-suite-point/protocol.md)

All arms receive exactly the same anonymous provider predictions and labels. The arithmetic mean of all providers, a fixed Brier ranking with every prefix from one through all M evaluated on fit, and regularized logistic stacking use the same fit set. Save ranking, prefix scores and selected length. Freeze all three on validation, IID and shift. Full Brier is the mean sum of squared class errors, twice the positive-channel score in a binary problem. Sample task-level results or fit-optimal tree selection do not establish that mutating solves an individual compositional law.

## External test

Use the scikit-learn copy of the UCI Wine Recognition dataset (178 chemical analyses, 13 features, three cultivars). Wine is outside all 19 generators. The five StratifiedKFold outer splits are disjoint at test, shuffled with seed 7709. For fold f indexed from zero split the outer-development set into 75% meta-fit and 25% meta-validation by stratified train_test_split with seed 7909+f. Sort original row IDs before the inner split. Create four stratified OOF folds on meta-fit only with seed 7809+f. Each provider predicts these rows exclusively from the other three inner folds. Refit the six providers on meta-fit only and use those frozen models for both meta-validation and outer test. Use all held-out examples exactly once, and both preregistered GP seeds per fold. Outer fit/val/test sizes are (106,36,36) on the first three folds and (107,36,35) on the last two.

Provider order and settings are fixed: standardized logistic regression (C=1, lbfgs, 1000 iterations), Gaussian naive Bayes (variance smoothing 1e-9), standardized distance-weighted 9-NN (Euclidean brute force), decision tree (depth 3, leaf minimum 4, seed 7717), 96 extremely randomized trees (sqrt features, leaf minimum 2, seed 7718), and training-fold univariate ANOVA top six features followed by scaling and shrinkage linear discriminant analysis (lsqr, auto shrinkage). Other settings take the installed scikit-learn defaults. Fix all preprocessing, provider ranks and ensemble parameters inside their assigned training split. Input SHA-256 for raw float64 features is 8edcf3903afd97c64d51e0212eb10b213f7943da650574d1c055b836c5c35d37, int64 labels b6514e07a6d27854e0da000ca82d8d8cc3d0cb904c51600344ca34f1ee04884b, and the int16 five-fold row-role and inner-holdout manifest 5d5836ef8966d07e338f9c854bc048790d822ee229d16f2ffa4f6f66bc14deca. All digests use C-order little-endian values. [Dataset and provenance](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html) · [UCI original](https://doi.org/10.24432/C5PC7J)

Use the same six GP-operator families, budgets, thresholds, selection criteria, three cheap baselines and GP seeds. Score full-class Brier over the 178 held-out cases equally, averaging the two separately trained GP restarts' losses per fold. Report all five paired outer-fold differences and their spread descriptively. There is no independent external shift in this design. Overlapping training folds and a single small dataset limit any broader transfer inference. A negative observed retype-minus-identity difference on Wine provides a separately reported external directional replication; its opposite is retained as a counterexample. No combined synthetic–external score.

## Verification and antecedents

Replay the native stock and retype on the same new data and seeds through an independent uninstrumented route. Check the sham and refresh with native tests for eligibility, same pre-event random consumption, preserved inputs and replayability. Regenerate predictions for serialized trees and all three baselines, verify probability mass for C=2,3,4,5, and independently calculate the two-budget primary differences from per-start rows. Check no external test or validation ID occurs in the recorded training-fold scope for any fitted base model. Keep unfiltered per-search and per-split results.

Langdon, Barrett and Buxton used same-arity replacement with existing arguments while combining neural networks, changing on average 10% of functions in programs receiving point mutation in a mixture of operators. The present experiment introduces the identity and same-family controls to resolve an ambiguity in our own preceding deployable-flag study. Ting and Witten used out-of-fold base probabilities for stacking; their reported contrast concerned classification error and linear multiple-response regression on other datasets. Here OOF inputs support a held-out test of Brier-optimized GP with a separate logistic baseline.
