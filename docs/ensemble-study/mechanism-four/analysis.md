# Reading the paired comparisons

Every method in one bank sees the same source examples and the same audit set. In the eight crossed scene variants, the same seed also supplies the same latent scene signals, event labels, specialist regions and underlying noise draws. Changing a switch then changes the forecasts on those cases. A cell is a setting such as `h1c0s1`, with provider-noise heterogeneity and specialist strength enabled and shared error disabled.

* The **factorial** average first averages the eight cell values within each seed. The paired 95% percentile interval resamples complete data seeds, keeping all eight cells together. The independent count is eight screening seeds or 24 confirmation seeds.
* The **standard** average gives equal weight to each of 30 fixed standard-v6 families. Its interval resamples seeds separately within each fixed family. The **legacy27** average uses the same fresh data for the 27 inherited standard-v5 families. Each scenario has two seeds in screening and four in confirmation.
* Within one cell or control, paired intervals resample that setting's data seeds. All 10,000-draw intervals use seed `84100 + round`. A negative Brier difference favors the method named first. Scope is the specified generator, data sizes and fixed search seed.

Observed Brier scores use the sampled audit labels where available. Conditional expected Brier integrates over each binary audit label using the generator's event probability on that same input. Both scoring rules use the full two-class loss. On the older finite-support controlled laws, Brier integrates both labels and support points. AP measures positive-class ranking, and macro-F1 uses the usual argmax decision. The suite contains multiclass tasks, so there is no full-suite binary-AP average.

The factorial-effects table computes high minus low for each switch, averaging over the other two. For a two-factor interaction it first computes the difference for one switch and then the difference of that difference across the other switch, averaging over the third factor. Three-factor rows are the next-order difference. Every contrast is computed within seed before resampling. For `reference=absolute` the quantity is the change in one method; other rows measure how the switch changes the difference between the named methods. These intervals are descriptive, without multiplicity adjustments. The prespecified decision uses the held-out round-four comparison.

Regenerate the summary files using `python stats_four.py R` in this directory. The per-bank score tables, absolute levels, paired contrasts, family means and factorial effects are archived by round. Run `python geometry_four.py` with the repository on the Python path to reconstruct the first round's arithmetic-mean decomposition.
