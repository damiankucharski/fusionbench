# Does selecting inside a fixed mixture change which provider direction wins?

This finite-menu study uses the 24 generators in standard-v3 registry order, eight paired banks per generator. For zero-based scenario index i and repetition r, set the data seed to 4810000 + 1000i + r. Use the public `generate_dataset(name, n_per_split=1024, seed=seed)` with default constructor settings. Use the first 192 fit rows as one labeled selection sample for both menu rules, Top-N and both stackers. The extra 832 fit rows are unused. Score the entire 1,024-row standard test split only after naming both candidates. The test hook on environment_shortcut can change its environment mixture. Use one numerical thread.

The fixed prior b is the full arithmetic mean of the provider probability vectors. In stable tie order the candidate menu contains b, all individual providers in input-column order, then all two-provider arithmetic means in lexicographic index order. Exact numerical ties keep the first candidate. The ordinary selector minimizes full-class Brier of the candidate T on the fit rows. The in-mixture selector minimizes full-class Brier of b + 0.25(T − b) on those same rows. Both primary deployments are b + 0.25(T − b); tree weight and inputs are identical. Also report the unmodified T from each rule, the prior, a Brier-ranked Top-N over all prefixes, and C=1 logistic stacking on probability and logit features. The menus use no evolutionary search.

For a candidate T and split, compute D(T) as mean squared Euclidean displacement from b, summed over classes. The deterministic check requires D of the in-mixture fit winner to be at least D of the ordinary fit winner on the fit sample within 1e−12. The primary empirical measurement is paired test Brier of the in-mixture winner minus the ordinary winner, with both mixed at weight 0.25. Report D on independent test rows as a secondary outcome. Classify differences within 1e−12 as ties, give each scenario equal weight, retain opposite signs, and report per-bank data. A 95% descriptive sampling interval uses 10,000 draws resampling the eight banks within each fixed scenario, with RNG seed 4810999. The finite-menu theorem imposes no sign on independent test Brier.
