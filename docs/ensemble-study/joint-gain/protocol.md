# Joint gain across all rows and at least three of four folds

Three manual experiments fixed before evaluating any new outcome. Study starts from FusionBench a485161 and OKAPI e9e0da8. The earlier fold study saw seven selected improvements on three folds that were losses on the pooled fit set. All seven also lost to the original anchor on audit. Here each series uses separate new banks. All arms are prespecified and can run independently.

## Shared intervention

Use the same 16-generation native search, singleton and all-provider mean founders, budget, rounding, size objective, fold assignment (whole groups, seed = data seed + 3,000,000), empirical initial anchor and tie breaks as in the preceding study. Let P be the pooled fit-Brier gain against the best initial founder and F be the second-smallest of its four paired fold gains. Training paths are pooled, fold, or joint. Joint training scores min(P,F) continuously, in the same native units as F; variants can breed even when below the anchor. Its sign is positive exactly when both gains are positive. Terminal joint selection uses a different operation: retain any final survivor with P>0 and F>0, rank the eligible ones by F, otherwise deploy the anchor. The veto-only control deploys the ordinary fold winner if eligible and otherwise the anchor, without reconsidering other survivors. Fold and pooled terminal rules keep the anchor available and prefer it on ties. When comparing terminal policies, hold the actual evolution and finalist menu fixed. Downstream oracle diagnostics only inspect already frozen choices. All policies deploy one tree. Lower full-class Brier is better, including the controlled binary excess 2 mean((p−q)²).

For every evaluated dataset include simple mean, development-Brier-ranked best-prefix Top-N, standardized probability logistic stacking and fixed regularized native-pattern OKAPI. For changes in risk, form differences within data bank, then resample independent banks. Where a bank has multiple search seeds, average their results within bank before computing the risk contrast. Report the point, both ends of the 95% percentile interval and actual denominators. Each round has one primary; secondary comparisons and across-family extremes are descriptive. Report each primary separately without a single omnibus discovery claim.

## 2 · Can the search leave a weak start?

32 independent seeds 288200–288231. Reuse the six anonymous provider-score columns, role permutation and common uniform generated by NativeSwitch(role_seed=data seed).draw, using independent NumPy default_rng([seed,1]) for 1,536 fit rows and default_rng([seed,2]) for 4,096 audit rows. Use the first 192 fit rows for the smaller sample, one fold group per row. Keep raw scores and uniform draws paired across laws. Generate labels with q equal to provider A (the correct predictor is in the founding population), or q = min(A,B) (correct two-provider rule outside the founding population). At the population level no singleton and no all-provider mean can equal the minimum almost surely. Fitting does not know the anonymous IDs or q. One live fold-trained native path with seed data seed + 1,000,000 per condition. Compare its frozen terminal policies and all references. Primary: joint terminal minus fold terminal conditional excess when the true rule is MIN and only 192 rows are available. For this test only, call the joint rule noninferior if the upper end of the 95% paired percentile interval is below +0.002 full-class excess Brier (10,000 bank draws, seed 97827). This fixed tolerance is an experimental choice, not a domain requirement. Also report the observed difference and interval without relying on that tolerance.

Record whether a function agreeing with q on every fit and audit row was evaluated, survived and was deployed. As a diagnostic, separately offer only the initial anchor and the correct known rule to a fit-only selector; measure acceptance with pooled, fold and joint scoring. This witness measures selection power when discovery is guaranteed. It must never enter the live GP.

## 3 · Use joint gain during evolution

All 25 fixed standard-v4 scenarios on four new data draws each (288400–288403), 512 fit and 512 test rows, native search seed zero. Compare three genuine native paths, with every terminal policy evaluated on its own frozen path. The primary is joint-trained/joint-deployed minus fold-trained/joint-deployed test Brier, equal weight per family; 10,000 bank bootstraps within each fixed family, seed 97828. Broad gain on this panel requires an interval below zero and more improved than worsened scenario means (ties within 1e−12). Compare against ordinary pooled native GP and all four references, and inspect family-level regressions.

A separate controlled study uses 24 new banks 288300–288323. Run the severe signal case from round 1 and the weak MIN case from round 2, 192 fit observations each. For each fixed bank run three paired native search seeds (data seed + 1,000,000, +2,000,000 and +3,000,000), identical folds for all. All three paths and all terminal policies remain in scope. Fit the four fixed references once per data bank and law, with regularized reference seed data seed + 1,000,000. Report mean risk, within-bank maximum minus minimum risk across the three searches, worst-of-three risk and exact outcome frequency. A range from three searches describes observed sensitivity and is not a population variance estimate. Use the same bootstrap seed, resampling data banks. The counted search seeds are not independent data replicates.
