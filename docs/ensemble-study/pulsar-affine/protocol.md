# HTRU2 preregistration for an extra maximum and effective regularization

## Data and holdout

The HTRU2 radio survey is a new population for this study. Robert Lyon (2017), HTRU2, UCI Machine Learning Repository, DOI 10.24432/C5DK6R, CC BY 4.0. The official CSV contains 17,898 distinct eight-dimensional real feature vectors and the original binary pulsar-candidate annotation (1 = pulsar). The eight statistics describe the integrated pulse profile and dispersion-measure/signal-to-noise curve. Freeze a stratified one-third candidate-level test set (seed 94107). Five-fold stratified OOF scores in the remaining development set use seed 94108, with a full-development refit for the held-out inputs using seed 94119. Each OOF score excludes its own row and all preprocessing is fold-local. No exact repeated input vectors occur. The public file lacks pointing, source, and site identifiers. Uncertainty is conditional on the selected training bank and assumes independently sampled candidates, not independent skies or sources. Use no test information to choose any model, report contrast, feature or hyperparameter.

## Frozen competitors and equal budgets

Use the same six classifiers and fixed defaults as the WDBC transfer, in the same index order: standardized logistic regression, standardized distance-weighted 5-NN, Gaussian naive Bayes, 100-tree random forest with minimum leaf size 2, 60-step histogram boosting with seven leaves and L2=1, and LDA. Include every individual, with the comparator individual chosen by OOF Brier. No search across regularization, pair rules or alternative pools.

Select the pair with largest mean absolute positive-probability disagreement on OOF rows, first lexicographic pair on ties. Freeze the lower-index provider A, the other B, and g=max(A,B). ## Raw-probability geometry controls

Use the OOF-fitted StandardScaler on the original two channels per provider. Let Z denote these standardized columns, q the positive columns of Z, and h the OOF-standardized g. Decompose h by least squares on [1,q] as h=s+r, where s is its affine projection and r is the orthogonal residual on development rows. Freeze this projection, the scaling constants and the pair before any test predictions. The following matched raw-head diagnostics use the same C=1 lbfgs, 2000 iterations and a tighter tolerance of 1e-10. Add a pair of columns [-f,f] after standardization; never independently renormalize s or r. Each head gets one fit on all OOF labels. The projection is a single label-free OLS fit.

* Flat, with zero-padded extension. Compare against a literal duplicated standardized A channel pair, and against multiplying A's two existing standardized columns by sqrt(2). Splitting a weight equally across two duplicate coordinates halves that coordinate's squared L2 penalty. The last two parameterizations therefore have identical fitted probabilities at the optimum. Check their maximum absolute prediction difference on OOF and test (target <1e-5), and report duplicate versus flat Brier. The sign of that difference measures which penalty worked better on this holdout.
* Full extra maximum h versus projection-only s. The projected feature cannot extend the affine function class, but changes its effective L2 geometry along the linear projection direction. Replacing s with h adds the residual while retaining the same linear component and its original scale.
* Residual-only r versus zero-padded flat. The sole extra fitted direction is orthogonal to the original affine basis on OOF; it cannot serve as a duplicate of that basis. Both models retain the original penalty on the original coefficients. Flat, projected, residual and full share the same supplied dimension and fit-label count.

## Decision and reporting

The two co-primary gains are test risk(projected) minus risk(full) and risk(flat) minus risk(residual), using positive-class Brier (mean squared probability error). Report both paired point estimates and one-sided percentile-bootstrap lower bounds using the same 10,000 candidate resamples, seed 94120. Require **both** 0.025-quantile lower bounds to exceed zero before claiming the nonlinear component improved this problem. Report two-sided descriptive intervals for duplicate versus flat, and all model scores, average precision, observed residual variance fraction, selected pair, Top-N size, parameter/input counts, iteration counts for numerical controls and elapsed time. A failed decision does not establish equivalence, and a single survey cannot establish transfer to independent instruments.
