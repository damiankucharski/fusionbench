# Full default-suite regression test of native point mutation

One synthetic mechanism can reveal a missing operation or explain one failure. The other FusionBench families serve as regression tests for a change proposed on that mechanism. Freeze one configuration before inspecting their outcomes; show the result and variability for each scenario. A mechanism-specific discovery, a favorable average and a broad improvement across families are distinct claims. If the panel motivates another code change, use fresh independent data to verify it. A transfer claim additionally needs a previously omitted family or an external task. This is a standing rule for the research program.

Use one ordinary search per reported restart. All arms fit the same normalized Brier objective, with unrounded loss for scoring and native rounding for evolutionary selection. ## Outcomes

Primary is full-class Brier (mean sum of squared class-probability errors), with per-scenario paired differences ON minus OFF and two-sided 95% t intervals across the eight independent data banks after averaging the two GP restarts. Give start-level results, per-bank spread and class count for every individual scenario. Report aggregate equal-scenario mean descriptively and retain all scenarios with unfavorable or inconclusive results. Also report macro F1, accuracy, log loss, known conditional excess Brier where the scenario supplies its oracle, and node count. These are distinct outcomes; GP optimizes Brier throughout. The native fitness skill is 1 minus half of full Brier. In binary cases, full Brier is twice the positive-channel convention used in the preceding mechanism studies. All cheap baselines are evaluated on the same full probability vectors as the native arms.

This is a finite suite with related generators, many contrasts and eight independent data banks per case; the individual unadjusted intervals are descriptive. Compare the common primary, document exceptions and run independent reconstruction of baseline scores, normalized model predictions and true evaluation counts.
