# Round 1. How does selecting more fixed predictors affect apparent and actual loss?

Freeze the following design before evaluating any selection outcomes. The unit of replication is a newly drawn bank. This experiment studies independent binary observations and a known finite set of prediction rules.

## Population and available predictors

Draw an anchor probability p uniformly from {0.2, 0.4, 0.6, 0.8} and six independent fair signs. Provider pair j reports p + 0.10 sⱼ and p − 0.10 sⱼ for class 1. Thus the arithmetic mean equals p and all signs are observable from the providers. Candidate 0 returns the mean. Candidates 1–63 add 0.10 times a product of signs to that mean. The six-bit mask of each candidate ID determines which signs enter the product, with bit 0 denoting the first sign. The population law in the null arm draws Y from Bernoulli(p). In the information arm it draws Y from Bernoulli(p + 0.10 s₁). Candidate 1 realizes the informative alternative. No candidate learns parameters on labels. Select the candidate with smallest validation full-class Brier, breaking ties by earliest index.

On source IID data the oracle Brier is 0.400 in the null arm and 0.380 in the information arm. In each case excess risk is twice the mean squared difference between a rule's positive-class probability and the true conditional probability. Orthogonal sign products imply that every non-anchor candidate has null excess 0.020. In the information arm the anchor has excess 0.020 and each non-anchor other than candidate 1 has excess 0.040. Compute and check population risks by summing over all 256 feature states. On the shifted test, change the anchor masses to (0.4, 0.1, 0.1, 0.4) and replace the positive arm's true sign effect by −0.10 s₁. The null arm retains its original conditional label law. Report shifted scores separately.

## Data roles and estimates

Use 32 independent bank seeds 4100000–4100031. Within each bank use separate NumPy SeedSequence entropy [bank seed, stream] for development (stream 0, 640 rows), validation (1, 512), clean audit (2, 2,048), IID test (3, 4,096) and shifted test (4, 4,096). Draw features and label uniforms once per stream and share them across the two laws. Retain the first 32, 128 or 512 validation rows. Retain the first 1, 4, 16 or 64 candidates. Every policy within an arm faces the same held-out examples. The other samples never feed selection.

Report the selected candidate's validation, clean audit, IID and shifted Brier. Report optimism as audit minus validation. Also calculate extra optimism relative to the fixed anchor using the same rows, and exact optimism using source population risk. Source selection regret is the selected rule's true risk less the minimum true risk available at that menu size. Record how often the selected rule attains that minimum. Report the penalty from excluding better rules separately. The prespecified summaries compare menu sizes at each validation size, including 64 versus 1 for the null and how often the positive rule wins for menu 64. Compute two-sided paired 95% t intervals across the 32 banks. Related policies and the two coupled laws do not count as extra independent replicates.

Fit arithmetic mean, development-ranked Brier Top-N and probability-feature logistic regression on the 640 development rows of every bank/arm. Run the previously fixed regularized native OKAPI procedure on the first eight paired banks with its data and search seeds set to the bank seed. These are separately fitted reference predictors using the twelve original probabilities. They do not enter the 64-candidate selection menu. Record fit time, prediction results on validation/audit/IID/shift, and native selected type. Report comparisons with native on the common eight banks. No tuning or downstream promotion depends on these results.
