# Does internal validation overstate the incumbent tree's gain over averaging?

Freeze the following diagnostic before evaluating round one. The incumbent is regularized NativePatternOKAPI with L2 strength 0.25, mixed-branch GP budget 600, and the existing flat, augmented and GP families. Use all 24 scenario IDs of standard-v3 in registry order, default constructors, six banks each. For scenario index i and repetition r, the data seed is 4610000 + 1000i + r and the separate GP search seed is 6610000 + 1000i + r. Use the data seed as the incumbent's split seed. All comparators on a bank receive its same provider tensors.

Draw 640 labeled source rows on stream 0 (`sample_split(...,"fit")`). The incumbent's historical 70/30 split uses 448 discovery and 192 internal validation rows. It uses validation to nominate the GP champion among distinct visited trees and to choose among GP, flat and augmented families. Retain the three discovery trees for a like-for-like comparison on internal validation and an independent 1,024-row source audit (stream 3, fit law). The primary endpoint is mean relative optimism: the winning discovery tree's validation gain over arithmetic mean minus the same frozen tree's independent source-audit gain. Positive means observed validation overstated the relative gain. Also report absolute optimism (audit minus validation loss), component-wise scores and counts of changes from apparent improvement to independent harm. The archive search precedes one family comparison, so the selected GP already depends on internal validation.

Report the deployed incumbent separately: its flat and augmented heads refit on all 640 rows; its GP component remains the frozen inner champion. Score it and arithmetic mean, fit-Brier Top-N, and fixed C=1 probability and logit logistic stacking on the independent audit and two test conditions. Use 1,024 rows drawn via the scenario's actual test hook on stream 1. Most generators have identical fit and test laws; environment_shortcut uses its test mixture. Then corrupt one anonymous provider at 50% of these same test rows with the benchmark's standard provider_swap streams; retain the labels. This deliberate input perturbation measures transfer separately from the independent same-law audit. Audit and test rows never train or select. Regroup per scenario then give each scenario equal weight; label intervals from resampling banks within fixed scenarios as Monte Carlo sampling intervals. One BLAS thread per worker and at most three workers.
