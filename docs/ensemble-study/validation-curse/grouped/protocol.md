# Clustered multiclass GP population audit

Use eight fixed providers, five classes, 24 independent training units with eight correlated annotations per unit. Sample provider probabilities independently conditional on one latent probability vector per unit. All eight annotations in a unit share the provider tensors. Draw each annotation independently conditional on unit probabilities with probability .2; otherwise use a shared label drawn once per unit. The observable marginal posterior is the arithmetic mean in the null arm or 80% first provider plus 20% mean in the signal arm. These are stylized clustered categorical observations. They have no medical or remote-sensing inputs.

Use 12 paired banks per arm. Use data seed 4720000+i and independent GP seed 7720000+i. Compare all surviving trees after 0, 4 and 16 complete generations of native GP, population size 8, offspring multiplier 2, tournament size 3. For each snapshot identify its plain empirical train-Brier winner; compute the retrospective best, median and worst conditional expected test losses across survivors on 2048 fresh feature vectors (exactly integrating the unknown test label at each vector), plus the losses for mean, Brier Top-N and probability LR. Also use a separate labeled test on these vectors and report squared distance to the known conditional probability (excess Brier). Fit methods on the same 192 rows. The retrospective test minimum estimates best-in-snapshot on a finite feature bank; it is unavailable to training. No extra split in this experiment.

If the primary round-two intervention implements an uncertainty penalty during evolution, repeat on fresh roots 4730000/7730000 using the same search, with z=0 and 1 and row-wise or equally weighted true groups. Compare identical final plain empirical selection as a trajectory-only endpoint and selection using each training objective as a deployment endpoint. Freeze all settings before round-two scoring. This secondary diagnostic tests whether accounting for the actual number of independent units matters.
