## Fixed samples and learners

For each bank use min(64, original fusion-development size) records, preserving the complete original held-out test. Digits uses 64 of 449 rows; the small three-class pools use all 44 available fusion-fit rows. For a downsampled bank choose a uniform subset without replacement with NumPy default_rng([original_partition_seed, 96301]), sort selected row positions to preserve archived order, and store their underlying example IDs. Do not stratify, redraw a split, or select a provider configuration in response to outcomes. Two provider pools that use the same source digit partition use the same selected example IDs. The test minimum, outcomes and predictions never feed candidate fitting or the gate.

Use the exact locked second-round guard, thresholds, candidate order, evaluation objective, inner/outer split rule and fitting defaults used in the synthetic panel. Set the native search and split seeds to the original partition seed for each bank. The native incumbent fits all available development rows using NativePatternOKAPI with L2 strength .25. The guarded family uses a 70% training subset and a disjoint 30% gate. The native procedure produces three actual candidate trees for the unchanged inner fit. The mean is the fixed fourth option. Raw selection chooses the smallest gate Brier among mean/flat/augmented/GP, with mean first in ties. The guarded policy uses the native bank-level sign-flip test against the mean with the locked multiplicity correction and fallback. Both use precisely the same four frozen candidate prediction vectors on gate and test, and have identical total label access. No refit follows the gate choice. Also evaluate the inner-training incumbent chosen on its own internal validation to separate the loss of training rows from the outer policy. Log candidates individually and record the gate and test Brier of the selected policies.

Use all-development arithmetic averaging, one training Brier ranking and all prefixes for Top-N, C=1 multinomial logistic stacking on probabilities and the same model on logits. Fit these methods with the public FusionBench classes. Benchmark all using full-class Brier (lower better) and report accuracy. Fit and test sizes, provider IDs, row IDs, frozen choices, score counts and prediction digests are recorded. Keep existing probability precision and column order from the source archives.

## Endpoints and interpretation

Report each of the six pools separately, with means over its eight paired partitions, ranges of per-partition guarded-minus-raw differences, and frequencies of selected mean. For the primary search contrast and secondary guarded-minus-raw held-out Brier contrast, compute the overall descriptive difference by averaging partitions within each pool, the three digits pools within digits, then the four underlying datasets equally. Also give the equally weighted six-pool contrast and comparisons to both incumbents and baselines. Selection optimism is the gate-to-test change in the Brier contrast with the fixed mean, reporting test contrast minus gate contrast for each policy. Independent selection plus the finite test sample and naturally heterogeneous partitions all contribute to this observed difference. Report every bank and failure. Shared records and earlier use of these test sets preclude population inference based on treating 48 partitions as independent. This experiment tests the synthetic round's already chosen rule; it does not select an operating point, estimate patient/scene-level performance, or tune on external outcomes.
