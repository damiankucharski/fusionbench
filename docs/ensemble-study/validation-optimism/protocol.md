# Preregistration for search gains and validation optimism

## Prior evidence and independent confirmation

The earlier seed-selection study saved individual fit-selected OKAPI champions, per-seed labeled validation risks and independent conditional test risks. Its subset-size analysis integrated over the possible subsets and compared ranking under context shift. The adoption study used part of a validation sample to nominate a tree then optionally switched to a baseline. Neither quantified B−A for the *same* A-selected winner across fixed nested pool sizes and an identical-copy control. Use the archived 16 banks in results.zip only for a labeled retrospective; previously viewed test scores make it unsuitable as the primary confirmation. Pair even/odd archived validation repeats (0/1 through 10/11). For each genuine candidate, conditional IID and shifted risks are the archived weighted test_clean/test_flip risks. Historical files lack fit risk and the mandatory baselines; restrict that panel to reconstructable quantities. All primary conclusions and comparisons with baselines use new simulation draws.

## One fixed source law, independent data and search seeds

Preserve the seed_selection.observations generator with seven positive-class probabilities, a balanced class prior and a 10% chance that the strongest input is inverted. Train on 384 labeled cases. Lock 16 new data seeds 98000–98015. Per seed fit twelve actual OKAPI champions (GP seeds 820–831, 10 generations, eight random initial trees, native NumPy, same population, objective and initialization as search_champion). Search uses only the fit labels; candidate i is its highest fit 1−Brier Pareto program. Count native fitness evaluations and wall time. Compare with the arithmetic mean, full-prefix Top-N minimizing fit Brier, probability-feature and logit-feature standardized logistic stacking (C=1). All use the same fit predictions and labels. For a separate total-label budget check refit the three supervised references on the union of fit and A for every selection replicate; mark their A loss as training loss. B and test labels can never change a selected model.

For each bank use twelve disjoint A/B pairs. Validation A and B each use independent balanced-prior draws with 10% probability of inversion, using unique RNG streams for observations and inversion masks. Report nested n=64 (primary) and n=256 (secondary) from the same 256 rows in each draw. Prespecify a fresh permutation of the twelve champions for each data seed and repetition using NumPy default_rng([99041, data_seed, repeat]); use that same order at both sizes. For k=1,4,12 select the lowest sample Brier on A among its first k, breaking ties by earlier position. Record its stable seed ID, nodes, fit, A, B, held-out IID and shift. Never reselect on B. Make a control archive by placing twelve exact copies of the randomly first program in that same order: all k must produce exactly identical predictions and losses. On a single pair its B−A need not be zero; expectation is zero.

For each fresh bank use independent observations(seed, 900, 8192) for paired clean and flipped test risks. Integrate each candidate's losses with weights (0.9,0.1) for IID and (0.5,0.5) for deployment shift. This reduces Monte Carlo variability while preserving each target law. The same test rows serve all methods and repeats within a bank. No test scores inform search or selection. No deploy-or-fallback gate is used or calibrated. Keep the fixed synthetic law and the repeat count even if a contrast is inconclusive.

## Primary estimands

Use one-channel binary Brier, lower is better. Define optimism O(k)=B(winner_k)−A(winner_k), fresh IID search gain G(k)=test(first)−test(winner_k), and apparent validation gain V(k)=A(first)−A(winner_k). O(k) includes A/B noise for any single pair. The paired excess O(12)−O(1) removes the first champion's A/B offset and directly contrasts the real menu with copies. Predeclare two primary tests on 16 **new banks** with n=64: excess optimism at k=12 > 0, and G(12)>0. For each, average the paired replicates within bank first, then use the mean and the lower bound of a two-sided 95% Student-t interval over 16 independent banks (one-sided alpha .025 per claim, Bonferroni). Declare simultaneous evidence only if both bounds exceed zero. Report both estimates and bounds even if either fails. Larger n, k=4, shift and all baseline rankings are descriptive. The copy control has identically zero G, V and excess O for every bank by construction; report its actually observed B−A. Archive results are analyzed separately. A fixed-law stress, not an estimate of the behavior of every search or dataset.
