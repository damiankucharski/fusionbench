For each row and provider, remove the true class, find the largest remaining probability and give its tied destinations equal fractions of one event. The primary population includes every row. The secondary population includes the provider's top-1 errors using the original lowest-index tie rule. Report the number of events and the fraction with all nine destinations tied. Assign rows alternately to halves within each true class in stored order. Learn wrong-destination frequencies on each half and score the opposite half, then swap. Each event receives a held-out prediction once.

For each provider, the conditional model uses a separate row of destination counts for each true class. Add symmetric Dirichlet mass 2, spread over the nine eligible destinations in each row. Use two baselines. The uniform baseline assigns 1/9 to each eligible destination. The popularity baseline pools wrong-destination counts over all true labels for that provider, adds total Dirichlet mass 2 split across ten classes, removes the query's true class and renormalizes. All frequency estimates for the errors-only analysis use only training-half errors. Empty conditional count rows predict uniformly.

The reported gain is baseline log loss minus conditional log loss in natural-log units per provider event, with tied outcomes contributing fractional log scores. Average the two held-out halves by event count within a provider and bank, then weight providers equally within a bank and the eight banks equally. Omit any provider-bank cell with zero events in both halves and report the effective counts. Comparing to popularity asks whether repeatable dependence on the true class helps beyond a provider's overall wrong-destination frequencies.

For each of 100 reference draws, independently permute the nine eligible destination bins within every observed row and provider. Keep the truth, fractional tie pattern, full/error-only membership and halves fixed. Use NumPy RNG entropy `[bank_seed, 62017, permutation_index]`, with zero-based permutation indices. Use the same permutations for paired B/E banks. Refit both frequency models on the permuted data and report the 2.5th and 97.5th percentiles of the 100 bank-aggregated gains. These are reference values under destroyed destination correspondence. Repeated digits partitions and their images overlap. The log-loss measure addresses wrong-class ordering and does not measure fusion Brier or identify the cause of a fusion method's ranking.
