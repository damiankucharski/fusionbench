# Can the identity of the strongest incorrect class improve a fusion forecast?

## Prospective forecast

Compare the existing six-coordinate rule against a fully specified augmentation on three target pools. All use three base learners. Digits uses the same raw images as the earlier study, with Gaussian naive Bayes (var_smoothing .01), distance-weighted 11-nearest-neighbors and extra trees (100 trees); scale pixels by 16. Use stratified disjoint 898/449/450 base/fusion-fit/test rows. Iris and UCI Seeds each use logistic regression (max_iter 2000), uniform 5-nearest-neighbors and a 100-tree random forest with preprocessing fitted on base rows. Use stratified disjoint 74/44/32 rows for Iris and 104/44/62 for Seeds. Use eight splits indexed from roots 3300000, 3310000 and 3320000 respectively. Repeated partitions reuse examples. This is one new pool on an old dataset and two new datasets relative to the preceding forecast study.

Keep the same nine synthetic candidates and archived eight-replicate synthetic mean method losses as in the [previous investigation](../external-coverage/protocol.md). Match class count, provider count and fusion-fit size exactly (10/3/449 or 3/3/44). Regenerate historical synthetic fusion-fit inputs for the new coordinates only. Use each target's fusion-fit inputs and labels to establish distances. Publish the forecasts before computing fusion-method losses on the new target tests.

**Base rule.** Use Euclidean distance between mean fit profiles across each cohort's eight splits. Coordinates are mean provider Brier/2, best provider Brier/2, pairwise top-1 disagreement, proportion of exact zero probabilities, mean maximum probability and unanimous-wrong fraction. Choose the nearest configuration, with lexicographic ID as the tiebreaker. Predict the five method mean losses from the selected synthetic case.

**Augmented rule.** Append (1) mean top-one minus top-two probability, over rows and providers, and (2) reproducibility of which incorrect class receives the highest probability. For each provider and true class, alternate its rows into two halves. Allocate the strongest incorrect probability to its class, sharing a unit vote equally across ties. Each half's destination distribution is shrunk by two uniform pseudo-observations spread over incorrect classes. Subtract uniform from the two distributions and take their dot product. Average over providers and true classes having at least two examples, divide by the maximum squared deviation of a point mass from uniform, and clip the final average to [0,1]. In a correct prediction the strongest incorrect class is a runner-up; in a wrong prediction it can be the winner. This statistic does not require a particular numeric ordering of labels. A diagnostic third rule adds only the margin. The same coordinates, weights and tie conventions apply to all targets.

**Primary endpoint.** Compare the absolute error of the predicted difference in full-class Brier (regularized native OKAPI minus logistic stacking on probabilities, C=1). Call the change useful on this panel if mean absolute error falls and improves strictly on at least two of the three target pools. Also report each pool, the sign allowing a practical tie of ±0.001, and Kendall tau-b over the five-method ordering (OKAPI, arithmetic mean, fit-ranked best Top-N prefix, probability LR and logit LR). Give per-split held-out scores. All method settings match the previous study. No tuning or substitution after seeing a target test.

## Two separate mechanism checks on historical banks

1. Compare the historical heterogeneous digits fusion-fit banks with high-signal finite-vote synthetic panels B (undirected errors) and E (directed errors), eight draws each. Test on one half of the fusion-fit rows how much knowing provider and true class predicts the identity of the strongest incorrect class using the other half; swap the roles. Report gains in nats per event against uniform and provider-wide popularity excluding the true class. Use total pseudocount two for conditional and pooled distributions and fractional ties. Independently shuffle incorrect-class identities per provider and row for 100 seeded references. Report an errors-only sensitivity and its effective sample counts. This diagnostic uses no target test labels.
2. On those eight historical heterogeneous digits banks and eight historical 10-class panel E banks, permute class identity independently in each row using the same permutation for all providers and the label. Use independent fit and test streams and the original optimizer seeds. Fit and test in the same scrambled regime. Row-wise confidence, margins, and mean-pool Brier survive this intervention, while stable class meaning across examples is removed. Compare raw and scrambled native-minus-probability-LR gap; compare full versus permutation-symmetric LR on matched feature scaling. Check mean-pool and symmetric-LR Brier invariance; probability ties can change index-based top-1 ties. The treatment removes all stable class-specific information including class priors and intercepts, so a loss change cannot be attributed only to one type of confusion.

The previous external test losses were known when choosing these mechanism checks. They are reported separately from the three prospective forecasts. Use CPU resources and keep the earlier v1 benchmark and all optimizer settings fixed.
