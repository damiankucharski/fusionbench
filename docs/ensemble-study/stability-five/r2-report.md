# Can a native weighted probability tree stabilize weak specialization?

Each fitted tree uses nonnegative weights shared across classes. Their sum is one. We optimized negative full-class Brier with a fixed derivative-free search, starting from equal weights. The regularized arm deducts a cost for departing from equal coefficients; the matched ablation turns off that cost. Both use 1 + 13M calls to the fit objective for M providers. Each arm deploys one native weighted-mean tree and omits exactly zero-weight operands. The coefficient prior can keep all providers active. This does not append a separately evaluated average to a deployed tree. [Native implementation](https://github.com/damiankucharski/OKAPI/blob/d1afe2b2164e67df5c9e157b84d8729a3850f65e/okapi/simplex.py) · [Protocol](protocol.md)

On 16 fresh weak-specialization banks, the regularized probability tree scored **0.48132** against **0.53915** for existing regularized native-pattern OKAPI. The paired difference was **−0.05784** (95% interval −0.08095 to −0.03675). Arithmetic averaging scored **0.48187**; the comparison against it remained unresolved (−0.00056, interval −0.00204 to +0.00102). Top-N scored 0.50068 and probability LR 0.50810. [Paired contrasts](results/round2-contrasts.csv)

The controlled ablation exposes the bias–variance cost. At weak specialization, adding the coefficient penalty reduced the variance of predictions across the 16 training draws from 0.01494 to 0.00266 in Brier units; squared bias increased from 0.00159 to 0.00471. The net loss decreased by 0.00916. With strong specialization, however, the penalty cost **0.02493** versus the same unpenalized search. The fitted weight on the informative provider averaged 0.347 with the penalty and 0.695 without it. The penalized tree used all eight providers in all three controlled settings. [Exact dispersion and weights](results/round2-dispersion.csv) · [Ablation intervals](results/round2-penalty.csv)

As a standalone replacement for regularized native-pattern OKAPI, this restricted pool failed the screening criteria. Over all 27 fixed families, full-class Brier rose from **0.25868 to 0.36851**, a change of +0.10983 (95% interval +0.10702 to +0.11261). The largest family regressions were parity (+0.42780) and weakest_link (+0.41399). The largest gain was rare_shortcut_noise (−0.08096). Logistic stacking scored 0.28603, Top-N 0.37894 and the mean 0.40088 on these same banks. On digits the penalty also hurt: penalized pool 0.04141, unpenalized pool 0.03031, regularized OKAPI 0.03305, probability LR 0.02951. The four digits splits overlap across resamplings.
