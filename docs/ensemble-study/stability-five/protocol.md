# Five trials of variance control for native ensemble trees

The motivating case is a population where simple averaging has small bias and no fitting variance, but better weighting is possible. The primary controlled task uses eight binary providers and specialization 0.25, exactly 128 training examples stratified by class and amplitude, and the exact risk over the 512 input patterns. Two control laws use specialization zero and 0.75. Each round compares arithmetic mean, fit-Brier-ranked best prefix Top-N, probability logistic stacking (C=1) and the existing regularized native-pattern OKAPI, with native seed and split seed zero unless specified. Count full-class Brier, empirical fit risk, exact population risk or held-out test risk and paired differences. Fit decisions can only use the released fit observations. The regularized method deploys its selected GP/flat/augmented tree without output anchoring.

Every round also includes every one of the 27 standard-v5 families (512 fit and 512 test rows per bank), and sklearn digits using logistic, five-neighbour and random forest providers trained on 898 separate images, 449 for fusion and 450 for test. Archive individual banks, absolute levels, all candidate versus regularized contrasts, all family changes and fitting cost. Blend-of-models diagnostics are explicitly ineligible for the recommendation. All work is local, with no change to the existing default.

Use new data for each round r. With base=270000+1000*r, use controlled seeds base through base+15, two standard seeds base+100 and +101 in every family, and four digits splits base+200 through +203. Round 5 extends those counts to 32, four and eight respectively, plus a nested stratified 100-fusion-example digits check on its same test images. The first four rounds therefore have 106 banks apiece. On the standard panel, resample data seeds within each fixed family before averaging families. Controlled intervals resample whole training banks. Use 10,000 paired percentile bootstrap replicates with seed 89000+r. Digits partitions overlap across resamplings of one dataset: report paired descriptive values only. Treat exploratory and per-family intervals as marginal. The standard panel and the three controlled laws are different estimands.

## 1. Reduce validation reuse at fixed search cost

Run the unchanged discovery search and both regularized heads. Retain a discovery-ranked shortlist of eight unique GP candidates; compare to one candidate and to usual unrestricted validation ranking. Rank the shortlist by raw discovery loss, then native first-visit order; validation and family choice preserve the original tie rules. Each arm deploys its own winning family. Use shared discovery/head refits. The main contrast is gp_top8 minus regularized on weak specialization. Compare held-out validation optimism for the pre-refit candidate and record which family won. The shortlist changes GP eligibility as well as multiplicity.

## 2. Fit a native probability pool with a penalty for unequal weights

Use a single native WeightedMeanNode with nonnegative weights summing to one. Maximize minus full Brier minus lambda times the squared distance of the weights from uniform, with lambda=sqrt(M/N). Both the equal-weight start and directions toward individual providers are label-free. Try one full step, then two sweeps each at steps 1/2 through 1/64; all vertices in a sweep start from the same incumbent, ties keep the earlier winner. Compare an otherwise identical fit at lambda zero. The primary contrast is regularized simplex minus existing regularized OKAPI; the ablation compares simplex minus the unpenalized probability head. This imposes a coefficient prior, may keep every provider, and narrows the function class.

## 3. Select one representative tree after perturbing the training sample

Fit the standard regularized pipeline once on the original bank, then on three within-class bootstrap resamples with their original class counts. Use bootstrap seeds 1061,1062,1063 in class order and optimizer seeds 1,2,3; keep the internal split seed zero. Choose the tree closest in squared full-probability distance to the four-tree arithmetic prediction on the original source inputs; ties favor the first tree. Only this tree is deployed. Also measure averaging all four as a diagnostic of the price of single-tree deployment. Primary comparison: representative tree minus regularized.

## 4. Select between the stable probability tree and the expressive native pipeline

Create four deterministic label-stratified folds (seed 7304); compare the two complete algorithms' out-of-fold predictions. Measure the mean per-row Brier advantage of existing regularized native-pattern over the simplex tree and the usual paired standard error over rows. Refit on all source data and choose one native tree. Use a zero-margin rule and a one-standard-error margin; ties favor the simplex. Primary is one-SE minus regularized; both are eligible for confirmation. The standard error is a heuristic because the fold fits share rows. Both rules incur additional training cost.

## 5. Select once, then confirm on untouched banks

Eligible candidates from rounds 1–4 are gp_top8, simplex, bootstrap_medoid, cf_gain and cf_margin. For each candidate record differences against regularized within its own round. Screen on descriptive point estimates before looking at round 5: mean standard-v5 regression no more than +0.005, mean digits-449 regression no more than +0.004 and strong-specialization regression no more than +0.010. Among passing candidates choose the lowest weak-specialization difference. If all fail, minimize the largest positive threshold violation expressed in units of its corresponding tolerance, breaking ties by the weak difference. Further ties use the candidate order above. Freeze the chosen name and candidate-round data before computing round 5. Run only this candidate, the standalone simplex comparison and the original four references. The primary confirmation requires the upper 95% paired endpoint of chosen minus regularized on weak specialization to be negative. For a broad recommendation also require the panel's upper endpoint at most +0.005, strong-specialization upper endpoint at most +0.010 and descriptive mean digits-449 change at most +0.004. Separately report whether it beats the arithmetic mean on the focal task and the results on digits-100. Passing point estimates in the small screen is not confirmation.
