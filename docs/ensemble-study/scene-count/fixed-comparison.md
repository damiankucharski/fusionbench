# Reading the effect of scene clustering on one fixed decision

Additional mechanistic diagnostic specified after the main run began and before inspecting results. Use all 1,536 fit-pool scenes in each main bank to estimate how correlated eight observations actually are **for the decision between two fixed predictors**. The candidates are the simple mean and the single provider whose ID is randomly assigned by the generator, in both laws. Only on the signal law is this singleton the true posterior. The identity is privileged for this diagnostic. The evolving tree search receives no such information.

For each row set d = full Brier(single provider, y) − full Brier(mean, y). Average the sample variance of the eight d values within scene to get W. Across the 1,536 scene means estimate B, their sample variance. For conditionally exchangeable rows, E[W] is within-scene variance; B includes both the between-scene variance and one eighth of W. The estimated variance of a single random row is V = B + (7/8)W. At fixed total rows, the variance of the average d from eight-row clusters relative to one-row scenes is 8B/V. Average the variance components across banks within law before taking this ratio. A value of one means these helpers would see the same sampling variance at fixed row count. Square root of the ratio is the relative standard error. This comparison uses empirical label losses, no evolved trees. The estimated design effect is specific to the candidate pair and simulator.

Measure how often the two-option chooser achieves strictly smaller fit Brier for the prespecified singleton in each of the four actual fit layouts and how its average signed margin compares with conditional audit loss. Report these counts descriptively. Variation in a fixed decision shows one route by which clustering could affect selection and does not establish a causal explanation of any GP result.
