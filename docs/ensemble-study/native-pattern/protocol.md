# A single native OKAPI tree with score-only local parameter search

Freeze a single round on 24 November, before training or scoring the evaluation banks. The challenger must deploy exactly one native OKAPI Tree containing only original provider inputs and native operations. No external regression fit, conversion of regression coefficients, predictions from a fitted regression, autodifferentiation, numerical gradient estimates or learned ensemble weights in the challenger. Each public logistic stacker runs separately as a comparator. The intended advantage is over both C=1 logistic baselines in macro-average IID Brier across the complete fixed 19-family registry, including both multiclass tasks.

For each bank generate 640 training, 4096 fresh IID and, where predefined, 4096 shifted test examples from the standard generator. In registry order the bank seed is 1460000 + 1000 × family index + replicate (0–11); use streams 0, 1 and 2. Use the bank seed as search seed. No family-specific tuning or test-time selection. All controls get the full 640 training labels. Average each family's 12 fresh banks, then weight the 19 families equally. Calculate two-sided 95% t intervals over the 12 replicate-wise macro-averaged paired differences. Claim a win only if native-minus-logit LR and native-minus-probability LR both have upper limits below zero. Separately report how often each native topology was deployed; compare to the parameter-only and GP-only ablations; report per-family, leave-one-family-out, and 9-shift secondary results. The comparison concerns these fixed generators and default regressions.

On each training bank permute using SeedSequence([seed,51]); 448 rows D are used for structure discovery and initial parameter search, 192 rows V for archive and family selection. On D run ordinary six-operator native GP for 600 real objective calls with six balanced 15-node starters among 30 proposals. Collect complete scored programs, discarding redundant functional outputs when selecting extra features. Fit a native flat logit node on all original provider inputs using value-only direct search under the supplied scalar fitness. For the experiment the score is one minus half the full-class Brier. On binary problems use the native signed BinaryAffineNode with a free intercept in logit mode. On multiclass problems use a native shared-weight log-probability pool with per-row normalization. This multiclass family is structurally narrower than multinomial logistic regression on all class channels.

Select up to three nonlinear native programs from the discovery archive. With a flat head as the starting reference, score tentative logit-space additions with fixed weights ±.25 or ±1; take the best strict improvement and repeat. No oracle or supplied grammar for the task. Fit the augmented native head by the same direct-search rule. Choose among flat, augmented and validation-chosen GP by V fitness, with ties resolved flat, augmented, GP in that order. Refit only head parameters on the full 640 labels for the flat and augmented candidates. Keep the winning candidate type fixed, then generate the test sets. All candidates deployed by this policy are single native trees. The runner archives their structure, parameters, selection, evaluation counts, prediction fingerprints, mean and all-prefix Top-N controls and full-component outcomes. Before launching the evaluation banks commit the numeric optimizer schedule and implementation so winning settings cannot be chosen retrospectively. No second tuning round in response to these results.
