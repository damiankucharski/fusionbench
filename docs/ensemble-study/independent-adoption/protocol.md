# An independent gate for deploying a searched OKAPI tree

Freeze before any model fitting. Earlier stability studies selected a compact tree within an archive or shrank it toward a mean. Here the deployment decision chooses between the nominated tree and a separately nominated baseline, after observing fresh labeled paired losses.

## Worlds and split

Generate three independent probability channels uniformly on [0.02, 0.98]. Let T be their maximum (an achievable nonlinear OKAPI operator), L the sigmoid of a fixed linear combination of their logits with weights [0.5, 0.75, 1]. Draw native binary labels from Bernoulli(p), with p = w T + (1−w)L. Use w=0, 0.5 and 1 as a stacking-favorable control, intermediate case and tree-favorable control. The tree control intentionally aligns to the grammar, and the logit control aligns to a baseline. All methods receive exactly the same channels.

Use 12 data seeds 4100–4111. Each uses independent 256-row fitting, 512-row validation and 8192-row IID test sets. Also evaluate an independent 8192-row deployment population with the same covariate law and w replaced by 1−w. The middle world is a replicate. Shift labels never select a policy. Keep distinct data, label and GP random streams. The known conditional law permits low-noise evaluation of expected binary Brier on independent covariates; also report realized held-out label Brier.

## Competitors and independent decision

Fit a C=1 standardized logit-feature logistic stacker and two independent banks of four OKAPI searches (seeds 700–707), one 16-generation restart per seed, ten random initialization trees, multiplier two, 11-node cap and binary Brier fitness. Retain each search's fit-selected champion. Arithmetic mean has zero learned parameters. Each bank supplies the same six deployed alternatives to every selector. Also record fixed stacker retrained using all available development labels, outside this six-method menu, to quantify opportunity cost.

Use validation budgets 32, 128 and 512 (nested prefixes). Nominate the better of mean and stacker and independently the best of the bank's four trees using the first half's labeled Brier. Ties favor the stacker among baselines and earlier search seeds among trees. Freeze both nominees. The single primary gate observes only second-half paired losses D = baseline squared error minus tree squared error. Deploy the tree if the mixture of products of (1 + s D) for s in {0.25, 0.5, 1} reaches 20, else the baseline. Because D lies in [−1,1] and gate examples are IID, under the conditional null E[D] ≤ 0 each product has expectation at most one given the nominations. Markov's inequality bounds false adoption probability by 0.05 for this single decision under those assumptions. This guarantee applies per decision, not jointly over the sweep or under shift.

Compare with naive minimum validation Brier across the same full menu using all validation labels, nomination-half minimum, the same nominees compared on the pooled validation data, unconditional nominated tree, nominated baseline, fixed stacker and mean. This allows the cost of splitting validation to be distinguished from requiring stronger evidence. Track nominee true risk to score false adoptions and missed beneficial switches on fresh IID and shifted covariates. For policies selecting different nominees, use a common per-bank reference baseline nominated on the first half, and separately report deployment risk minus fixed stacker. Estimate false and missed rates for the gate also conditional on non-beneficial and beneficial nominees. Report counts; banks share each data seed and precision summaries use data seeds as clusters. Record fit, validation, IID and shifted Brier, search complexity/cost and choices. No hyperparameter updates after inspecting outcomes.
