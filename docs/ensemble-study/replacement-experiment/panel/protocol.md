# Frozen standard-v3 replacement panel

Use all 24 scenarios in the standard-v3 registry, in insertion order, and six independent data banks per scenario. For zero-based scenario index i and replicate r, use data seed 5230000 + 1000i + r and a distinct native search seed 7230000 + 1000i + r. Default source constructor; draw 640 source rows from stream 0 through the fit-domain hook and 1,024 independent evaluation rows from stream 1 through the test-domain hook. The EnvironmentShortcut generator changes its environment mixture between those hooks. Neither test predictions nor labels are passed into any search or promotion step.

Freeze the first 256 source rows for discovery. Use each subsequent contiguous block of 64 rows for exactly one generation's decision, for six disjoint gate blocks in total. The initial incumbent is the strongest provider singleton under discovery Brier; ties keep the first column. The four primary native methods share discovered providers, data, seeds, six generations of twelve offered proposal slots and up to eight breeders plus a separate deployment-incumbent slot. Keep the wrapper's fixed native mutation and crossover rules. Ordinary open search deploys the strongest discovery-risk survivor. The raw open rule promotes on positive empirical gate gain. The KL open rule promotes only when the best simultaneous gate bound is positive, but permits unconfirmed trees to breed. The KL strict rule imposes the same gate qualification on offspring admission to the breeder pool. The shared gate spends 0.05/6 at each generation and accounts for all twelve offered slots. Open policies must have the same proposal and breeding path at fixed discovery data and search seed. Guard and raw policies deploy their actual current incumbent unchanged.

Also evaluate ordinary open native search with all 640 rows for discovery, the same proposal-slot budget and no gate access. This estimates the opportunity cost of reserving 384 source labels and changes discovery score evaluations from 256 to 640 rows each. Report the common initialized singleton, arithmetic mean, Brier-ranked prefix Top-N, probability and logit logistic stacking (C=1). Fit the supervised controls on the 256 discovery rows and again on all 640. Record native discovery/gate calls, label-row evaluation counts, stored/distinct programs, deployment size and number of distinct providers where available. The labels given to the controls and native arms are drawn from the same 640 originals.

Two primary contrasts use full-class held-out Brier (lower is better): KL open minus raw open isolates the replacement threshold on a common evolutionary trajectory; KL open minus KL strict tests the effect of allowing unqualified descendants to breed. Report ordinary 256 and 640 as reference arms, full-suite arithmetic means, each scenario and win/tie/loss counts (absolute tolerance 1e-12). Intervals are paired, fixed-suite Monte Carlo intervals, resampling the six independent banks within each scenario and giving each scenario equal weight (10,000 draws, NumPy seed 5230999, 2.5/97.5 percentiles). These are separate marginal descriptive intervals. Report accuracy and resource counters descriptively. No thresholds, menus, budgets or seeds are adjusted using this panel. Use up to three single-threaded CPU workers. The separately controlled null and positive-mechanism experiments carry their own targets and hypotheses.
