# Composing two neutral subtrees

Use the four equally likely corners of two independent uniform bits A and B. Each bit and its complement is available as a provider whose positive probability is 1/8 or 7/8. The equal mean is always 1/2 and starts as an available native tree. The positive-class posterior is 7/8 if the bits differ and 1/8 otherwise. Each of the native subtrees U = MIN(A, 1−B) and V = MIN(1−A, B) identifies one positive corner and scores all other corners low. Each has exactly the same population Brier risk as the mean. Their MAX is the true posterior, so this particular constructive route uses two neutral intermediates. This is a statement about a specified route, without an assumption that all native paths have this property.

Use 32 new banks. For bank b use NumPy SeedSequence([5910000,b,stream]), discovery 128 independent draws on stream 0, six fresh blocks of 128 on streams 1..6, an independent evaluation sample of 2,048 on stream 7, and a provider permutation on stream 8. Search seed is 7910000+b. Evaluate the true expected loss on all four equally weighted corners. Use the common live native settings and the four prespecified policies. Record discovery and deployment of the exact rule, the best true excess in all offers, true improvement, distinct provider count and matched empirical Brier. Compare mean, ranked-prefix Top-N and probability LR fitted on the 128 discovery or all 896 labeled development rows. No privileged subtree enters the live native runs.

As a separate scheduled positive control give both open and strict breeding the same two physical native intermediates and two opportunities to preserve them. In generation one offer U, V and ten copies of the incumbent. In generation two offer MAX(U,V) only if both intermediates were eligible for breeding and otherwise offer the incumbent. Fill to twelve with incumbent copies. Remaining four blocks offer twelve copies of the incumbent, for the same six-block error budget. Open keeps U and V as breeders; strict requires each to have positive certified gain over the original incumbent. In both policies use identical KL-certified deployment. Compare targeted recovery and fraction of proposed targets passing. This measures the replacement/breeding rule when a known path is provided, and is deliberately separate from organic GP discovery. No parameter changes after observing results.
