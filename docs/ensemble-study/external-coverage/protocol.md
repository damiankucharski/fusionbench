# Does matching the prediction bank improve transfer of fusion-method comparisons?

The target is a labelled prediction bank, including its providers and fitting budget. Previous digits outcomes were known when proposing this study. Fresh splits of digits test replication on new partitions of the same images. The Wine dataset also appears in earlier work with a different provider bank. Neither dataset is a blind sample of future tasks.

## Endpoints and cohorts

Predict the difference in full-class test Brier (native regularized OKAPI minus probability stacking; negative favors OKAPI) and ordering of five fixed fusion rules (OKAPI, arithmetic mean, development-ranked best Top-N prefix, probability LR C=1, logit LR C=1). Compare the two predictions before opening the external test-score files. Count a gap within ±0.001 as a practical tie for the descriptive direction check. Report absolute error of the predicted gap and Kendall tau-b between the five mean-loss rankings. Treat external tasks separately. Eight repeated partitions of a dataset overlap.

Use 8 splits per external bank with stratified, disjoint base-train, fusion-fit and test rows. Digits heterogeneous uses three fixed learners from the published example. Digits LR bag replaces the learners with three logistic regressions, each trained on a stratified bootstrap sample of the same base images. Both banks use seeds 3140000–3140007, matched images and 898/449/450 rows per split. Wine uses the same three heterogeneous learners with base-standardized features, seeds 3150000–3150007 and 89/44/45 rows. Use the test partition only after publishing forecasts. Numerically repeatable profiles use the fusion-fit rows only.

## Synthetic panel and matching

For each external class count and fusion-fit size (10/449 and 3/44), draw 8 synthetic banks per setting; use 2,048 separate synthetic test rows per bank. Match these two settings before comparing any profiles. The existing-generator library includes multiclass_committee at nominal accuracy .60 and .95 and saturated at accuracy .95 and correlations .50 and .95, all with three providers. The expanded library adds the following five configurations of multiclass_provider_panel. Each uses strengths [1,.9,.8], temperatures [1.5,1,.75], shared logit noise fraction .65, hard fraction .15, hard signal multiplier .55. A uses separation 2.5 and continuous outputs; B uses separation 6 and vote counts [31,7] for two providers; C uses separation 6 and continuous outputs; D uses separation 2.5 and the same finite vote counts; E adds directed wrong-class logit bias 3 to B on hard examples. Common random streams pair configurations, including underlying rows for the vote ablations. Seeds and independent fit/test child streams are fixed in the synthetic driver.

For each target bank type (e.g. digits heterogeneous), average over its eight fusion-fit profiles. Find the closest synthetic configuration in the matched class-count/fit-size stratum separately in each library. Euclidean distance uses these six bounded coordinates without fitted weights: mean provider Brier/2, best provider Brier/2, mean pairwise top-1 disagreement, fraction of class coordinates exactly zero, mean maximum provider probability, and unanimous-wrong row fraction. A lexicographic configuration ID breaks exact ties. Distance has no calibrated statistical interpretation. A closer point is guaranteed possible when enlarging a library and by itself demonstrates no improvement in predictive validity.

Use the chosen configuration's eight synthetic mean test losses to predict the external methods' raw mean losses and rankings, without rescaling or fitting a regression. Freeze all three forecasts and synthetic results in the research branch before externally scoring any fusion model. Report failures alongside successes. The old all-19-family mean is only historical context, since its class counts, sample sizes and task weights differ.

## Mechanism checks outside the forecast

Compare the mean with a fixed sharpened mean (T=.5) and a fit-Brier-selected temperature on a fixed six-point grid. Include an exactly class-permutation-symmetric probability LR with the same multinomial training loss and L2 penalty as probability stacking. This restricts coefficients to one weight per provider and removes class-specific intercepts. Differences include the effect of estimating fewer parameters. Assess whether a single confidence adjustment accounts for an apparent stacking advantage and whether breaking class symmetry adds benefit. These diagnostic methods are excluded from nearest-neighbor selection and five-method rankings. Test score differences do not identify a unique causal mechanism. Record forecast errors, paired effects for synthetic finite-vote and directed-confusion interventions, ranks, source profiles, seeds and elapsed times. Make the extra generator accessible through the public API and keep the original v1 reference suite reproducible.

The production probability stacker standardizes each provider/class column. To isolate the symmetry restriction, also fit an unrestricted probability LR on precisely the same per-provider pooled scale as the symmetric LR. The paired pooled-full versus pooled-symmetric comparison holds scale and loss fixed. The original production stacker remains the forecast comparator.
