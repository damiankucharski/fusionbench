# Five full-data native GP trials

We ask whether native OKAPI can resist training-set overfitting when it evolves and selects on all available fusion examples. The reference in every round is the ordinary FusionBench OKAPIMethod using Brier, seed 0, one restart, eight generations, population ceiling eight at initialization, multiplier two, tournament size three, maximum 31 nodes and depth seven. Use only native single-provider initial trees (n_seeds=0). The terminal program maximizes fitness on the fitted population's Pareto front. These budgets produce a bounded constructive-search experiment. Each candidate uses the public tree operations and deploys a single tree. Retain ordinary references mean, Brier-ranked best-prefix Top-N, probability logistic stacking C=1, and previous8 (the earlier split-based regularized native-pattern pipeline with an eight-program validation limit; a different search family).

Use the same fit rows and the same audit rows for all arms within a bank. In round r the seed block begins at 380000+1000r. The equal, weak and strong finite-population stratified-pool laws get exactly 128 fit rows, evenly balanced across the four label and amplitude cells, and full-population Brier. For rare binary scene data use the public scene generator with interchangeable providers, scene error share .85, latent signal 0.9 S plus 0.8 E with intercept −2.0, label probability sigmoid(1.8 z), eight providers and fixed checkpoint zero. Source and target have the same data law, with independent scenes. Compare 16 fit scenes × eight rows with 128 fit scenes × one row. Use the same 256 audit scenes × eight rows for both fits of a given seed. The first four rounds use 12 seeds per controlled law from the base and 12 per scene setting from base+300. Round five uses 32 of each. Use every standard-v5 family (512 source and 512 audit rows each) with two seeds from base+100 in screening or four in confirmation. Digits uses four partitions from base+200 in screening or eight in confirmation, 898 images for the three base models, 449 for fusion, 450 for evaluation. Also fit on a stratified subset of 100 in round five. Digits partitions overlap.

Score full-class Brier (primary), fit Brier and audit macro-F1; also positive-class average precision on binary banks as a ranking diagnostic. For the exact law use weighted expected class masses. All learning and candidate selection take place before audit predictions are evaluated. Report paired changes, per-family absolute levels, standard-v5 macro giving equal weight to the fixed 27 families, and pooled estimands for each other setting independently. Paired intervals resample 10,000 times across data seeds within each family (seed 91700+r). Digits comparisons are descriptive. F1 and AP are secondary measures, the objective optimized is Brier or its specified modification. Controlled tasks approximate mechanisms observed in applications. Neither dissertation dataset is available for this study.

1. **Information lost by a split.** Compare ordinary all-row fit, the same algorithm fitted on the first floor(.7n) rows of a seeded permutation and selected on those same rows, and the same reduced fit reranked on the remaining rows. For the last decision score distinct final-population trees, including the original champion, prioritize the champion then first occurrence for ties in validation Brier. On the clustered cohorts split whole scenes after seeded permutation. In particular, the 16-scene case gets 11 discovery scenes and five selection scenes. The full vs reduced contrast captures reduced information during search, while split vs reduced holds the search fixed and changes terminal selection. Do not allocate any of the data withheld in this diagnostic to the next three interventions.
2. **Give the population an arithmetic mean.** Add an exact native tree averaging all providers to the starting population, increase the population quota by one, then run normal fitness selection. Compare with both ordinary native OKAPI and a matched extra slot initialized with a duplicate of a single provider. Measure whether the useful tree remains available and what it costs on nonlinear tasks.
3. **Stabilize predictions during evolution.** From the mean-seeded population score each program on all rows by Brier plus sqrt(8/n) times its squared full-probability distance from the mean of the source providers. Map this loss to the native unit fitness scale by dividing by 2(1+sqrt(8/n)) and subtracting from one. Include the same seed without the penalty and a zero-penalty objective with identical scaling to measure rounding effects. No external prior is evaluated at deployment.
4. **Account for uncertainty in each fitness evaluation.** From the same seeded start, rank trees by full-data gain relative to the mean minus 1.645 standard errors of the paired gain. Use independent scenes as the units where their identifiers are available; otherwise use rows. Score by the native paired-gain fitness mapping .5+atan(score)/pi, retaining the ordinary three-decimal rounding. Include a zero-margin control with that same mapping, plus the seeded ordinary fitness. This is an empirical regularizer under adaptive search, not a coverage guarantee.
5. **One independent confirmation.** Eligible policies are seeded_mean (round 2), pull_mean (round 3), paired_se (round 4). Fix the selection based on screening before running round 5. Compute point-estimate changes relative to ordinary full on strong specialization, macro standard and digits-449. Allow increases up to .010, .005 and .004 respectively. Among passing candidates choose the smallest average paired Brier change on the weak and scene16 settings. If none pass, minimize the largest positive normalized violation before minimizing that same average. Break exact ties in the eligible order. Confirm the joint target only if both weak and scene16 upper paired 95% endpoints are negative. Also require the panel and strong upper endpoints and the descriptive digits-449 mean to pass the specified limits for a broad recommendation. Report any failure and both observed differences from arithmetic averaging. One fixed optimizer seed isolates variation over sampled data. The old split-based method provides context only.

### Feasibility correction before screening results

The standard needle family contains 100 providers. Its exact native arithmetic-mean tree has 101 nodes, above the initial 31-node ceiling. Apply the common ceiling max(31, number of providers + 1) to the ordinary native baseline and every matched native intervention, including reduced and split. This changes only the needle family on this panel. All other budgets, the historical reference and selection criteria remain as specified. We stopped the initial screening processes before any score files were written and restarted all four with this correction. All standard families stay in the analysis.
