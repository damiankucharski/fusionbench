# Registered single-step native operator coverage pilot

Does scheduling the six default OKAPI operators once each find a useful extension more often than six uniform draws with replacement? This isolates one growth decision from a fixed singleton parent. Earlier rounds supplied a fitted gate, refined an existing threshold or changed a breeding slot. Here no family receives special admission, parameter tuning, operand order or oracle role.

Use 24 fresh independent data banks (118300–118323), each with six anonymous provider scores on the native-switch dyadic grid 1/64,...,63/64. Two hidden ordered signal channels remain fixed across the bank. On identical inputs and uniform draws use three label laws: FAR at 27/64, the existing affine-logit posterior, and min(A,B). Learners never receive hidden roles or conditional probabilities. Split each bank before fitting: fit 256, untouched validation 256, independent IID test 4096, independent shifted test 4096. In shift each channel is the minimum of two fresh uniform grid draws, all conditional laws unchanged. Choose each law's lowest fit-Brier single provider (first column on ties) as the frozen native one-node tree; this makes the growth site unique and leaves operand order fixed. No population search precedes or follows this step.

Use eight new proposal seeds per bank. Each chooses a companion uniformly among the other five providers, independently of labels. Apply the genuine native append_new_node_mutation to a fresh copy of that same parent, with the only site its root, restricting the allowed operator to each generated nominee and offering that companion as the new operand. Default six families in order: MEAN, MIN, MAX, WEIGHTED_MEAN, FAR_THRESHOLD, CLOSE_THRESHOLD. All three menus use six training-objective evaluations, charged even for identical predictions. Compare (1) six independent uniform family draws with replacement at the fixed companion, (2) a uniformly permuted schedule containing all six families once at that same companion, and (3) the first menu's family sequence with independent random companions (the first companion shared). The third arm trades fixed-companion coverage for wider operand exploration. Each occurrence of a family and operand gets the same native random-parameter seed across matching arms; later repeated occurrences receive fresh draws. Thresholds and weights use native constructors with no parameter fitting. Thus repeats of a stochastic family remain potentially useful. Neither selector ever sees an evaluation label.

Start each menu with the parent as the incumbent. Replace it only on a strictly lower fit Brier (tolerance 1e-12); use menu order for further ties. Log all candidates, family, provider, factory parameter seed, fit, validation, IID and shifted performance. On independent test inputs, squared error to the known conditional probability measures excess Brier with less Monte Carlo noise; report observed label Brier too. Record at least one candidate improving *fit* Brier, at least one candidate with smaller *IID excess* than the parent, whether the actually fit-selected child improves IID excess, and the selected child's gain vs parent. For comparison train all-provider arithmetic mean, ranked-prefix Top-N selected on every fit prefix, and C=1 regularized probability- and logit-feature stacking on identical fit examples and input features. All primary decisions use fit only.

Primary effects compare the fixed-companion balanced schedule with the fixed-companion uniform-with-replacement schedule: (i) change in probability of proposing at least one strict IID-excess improvement; (ii) change in the fit-selected winner's IID-excess gain. Average eight fixtures and three equally weighted laws within each bank; compute one paired contrast per bank. Use lower bounds from paired two-sided 95% Student-t intervals across 24 banks (one-sided .025 per primary test). Declare simultaneous support only if both lower bounds exceed zero. Per-law outcomes, alternative companions, validation, shifts and family frequencies are descriptive. This is a conditional one-step test at singleton roots, with optional retention of the parent; multi-generation survival, deeper attachment sites and a general advantage for an operator remain separate questions.
