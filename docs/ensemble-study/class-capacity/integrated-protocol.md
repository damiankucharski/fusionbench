# Secondary evaluation of the evolved-tree pipeline

The main registered comparison uses standalone native nodes. After inspecting its results, we fixed this additional deployment check on the two motivating cohorts: the original heterogeneous digits pool (8 splits) and the new shared 3/8 confusion condition (6 paired synthetic draws). These banks and earlier outcomes are already known. Treat this as a descriptive engineering comparison.

Run NativePatternOKAPI twice per bank, selecting between a flat class-affine head, a class-affine head with GP-discovered subtree inputs, and the ordinary GP tree on the existing held-out validation split. The two runs fix diagonal and full heads respectively. Keep the previous native search seed and 0.25 native regularization strength, and cap each individual head fit at 4096 objective evaluations. The pipeline fits multiple heads, so its total budget exceeds that of the standalone head. Record deployed Brier, chosen family, total fitness calls and exact agreement with replay of the selected tree. Compare with the earlier native procedure and the standalone head of the same kind on identical test rows. Use no test-based switch between policies.
