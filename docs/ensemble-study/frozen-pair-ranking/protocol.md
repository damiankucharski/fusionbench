# Can the deployment mixture still choose a tree when conditional label risks change?

Frozen on 2026-11-21 after publication of the [matched initialization results](../seed-geometry/README.md) and before opening any new research banks. The question comes from the earlier one-bit observer. Ordinary validation and the mixture selector compare exactly the same frozen trees. We distinguish a change in the proportions of observed contexts from a change in what the labels mean inside one context. Unlabeled target inputs are bit-identical between the two label mechanisms. The earlier context-stress study changed which expert failed, which could change the joint input distribution. Our earlier sentinel studies tested alarms, and the reference-copy study constructed observationally identical inputs. Here we locate where the ranking of the actual transported and validation-selected trees changes, and test whether a few new labels suffice to choose between them. ## Auditing the two selected trees with paid target labels

For each source bank, target prevalence, and repeat, sample an additional independent pool of 512 target inputs, shared bit-for-bit across λ. Use independent uniform thresholds in C=1 to couple the label mechanisms. Each of the two fixed trees supplies a positive-class probability f or g for every row. Let d=f−g and b=d(f+g−1). The conditional finite-pool loss difference is mean(b)+mean(d(1−2Y)). The first term costs no labels. Compare two unbiased with-replacement estimators of the second term. Uniform sampling uses each sampled value d(1−2Y). Gap sampling draws rows with probability proportional to |d| and uses mean|d|·sign(d)(1−2Y). These are Hansen–Hurwitz estimators. If every d is zero, the correct loss difference is zero and costs zero labels. In each complete draw sequence, read a repeated row's label once and count its multiplicity in the estimator. Record the actual number of distinct rows paid for across fixed 8, 32 and 128 draws. Use 64 independent paired repeated label-sampling sequences for estimating realized decision performance per target pool; the same underlying uniforms for selecting rows may be used in both designs. The source, target monitor and audit pool are separate; labels from the audit pool never enter the source selector, GP, baselines or independent test bank.

For a fixed labeled pool, the uniform variance minus the gap variance is exactly Var_rows(|d|)/k at k draws. This result holds for the displayed centering and independent sampling with replacement. The optimum can differ if extra label predictions supply another centering. Sign-correctness and independent target Brier are separate endpoints: reducing estimator variance does not guarantee better decisions in every finite budget. The secondary endpoint is mean independent-test selection regret at 32 draws for gap versus centered uniform sampling, relative to the better of these two frozen decisions at p=.50, separately at λ=0 and 1. Include all 16 banks, all eight repeats and tied trees. Select the transported tree only for a strictly negative audited gap, otherwise select ordinary validation. Report estimated-gap RMSE on the audit pool, paired interval across banks, empirical sign errors, deterministic no-target-label decisions, and the fresh test score. No labels from these oracles enter selection.

In gap sampling the signed residual divided by mean|d| is ±1. An exact fixed-draw 95% Clopper–Pearson interval for the Bernoulli proportion of positive signs gives an interval for the full pool loss difference. Report the frequency of intervals excluding zero, and whether they contain the fully labeled audit-pool difference. This statement concerns the finite pool with its fixed labels at a fixed k. There is no population or optional-stopping guarantee. Include a deterministic finite-pool reference: checking the k largest nonzero |d| gives a sharp distribution-free interval of radius sum_unqueried |d| / N with all unqueried labels adversarial. It minimizes that radius for any fixed number of distinct labels. It may often leave the ordering unresolved.
